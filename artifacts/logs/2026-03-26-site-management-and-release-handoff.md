# 2026-03-26 작업 기록

## 반영 내용
- 근무지 관리 2단계에서 드래그 배정 후 이전 조에 인력이 남아 보이던 문제를 수정했다.
- 근무지 관리 2단계에서 드래그 중 화면 가장자리 자동 스크롤을 추가했다.
- DB 마이그레이션 시 `A`, `B`, `C` 같은 조명이 `A조`, `B조`, `C조`로 정규화되도록 반영했다.
- 근무지 관리 2단계 검색 입력창이 포커스를 잃지 않도록 드래그 이벤트 범위를 배치 영역으로 축소했다.
- 윈도우 창/패키징 아이콘 경로를 정리하고, 회사 로고 기반 정사각 아이콘으로 교체했다.
- 내부 UI 로고는 기존 앱 로고 자산으로 복구하고, 앱 표기는 `교대근무관리시스템 V0.1.0`으로 유지했다.
- 수동 QA 실행용 체크리스트 문서를 실제 점검 기록 형태로 재정리했다.
