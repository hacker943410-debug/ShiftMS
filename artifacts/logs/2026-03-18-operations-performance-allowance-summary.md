# 2026-03-18 Operations, Performance, And Allowance Summary

## Scope
- 운영 관리 메뉴를 분할한 뒤 공휴일, 요율, 사용자, 양식 관리 흐름을 실제 저장/설정 기준으로 다듬었다.
- 양식 관리와 근무표 배포, 근무지 등록 화면의 사용성을 높이고 공휴일 표시 기준을 맞췄다.
- 수당 요율/계산 규칙을 근로유형별 행 기준으로 다시 정리하고 실적/수당 화면 연결을 이어서 보정했다.
- 실적 관리 화면의 경로 설정과 상세 필터 레이아웃을 실제 운영자가 쓰기 쉬운 형태로 손봤다.

## Today
- 운영 관리 화면을 메뉴별 컴포넌트 구조로 정리했고, 양식 관리 위저드를 초보자용 안내형 UI로 개편했다.
- 양식 관리에서는 등록, 수정, 승인, 기본 사용, 파일명 규칙 변경 흐름을 카드형 안내와 전용 모달 기준으로 정리했다.
- 공휴일 관리는 저장 목록과 API 원본 목록을 분리하고, 수동 등록/수정/이동/전체 반영 흐름을 붙였다.
- 요율 관리는 신규등록/수정/삭제가 가능하도록 확장했고, 사용자 관리도 수정/삭제까지 연결했다.
- 근무지 등록/수정 1단계 시뮬레이션 달력과 근무표 배포 달력에 등록된 공휴일 이름과 날짜 색상을 표시하도록 맞췄다.
- 실적 관리 화면에서는 승인 대기/완료 폴더를 직접 선택해 저장할 수 있게 했고, 상세 필터 폭과 검색 입력이 잘리지 않도록 레이아웃을 정리했다.
- 수당 계산은 `법정공휴일 / 평_대체근로수당 / 휴_대체근로수당 / 평_연장근로수당 / 휴_연장근로수당` 5행과 `기본 / 연장 / 야간` 3축 요율 기준으로 계산 모델을 다시 맞췄다.
