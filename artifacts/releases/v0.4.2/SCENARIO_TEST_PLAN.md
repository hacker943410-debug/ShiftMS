# v0.4.2 시나리오 테스트 계획

## 목적
- `0.4.2` 설치본 기준으로 근무지 패턴 문자열 저장 hotfix와 기본 운영 경로를 수동 확인한다.

## 시나리오

### 1. 빈 DB 설치 확인
- 설치 파일 `ShiftMgmt-Setup-0.4.2-x64.exe`로 fresh install 한다.
- 앱이 정상 실행되고 기본 로그인 화면이 표시되는지 확인한다.

### 2. 근무지 패턴 문자열 저장
- 근무지 관리에서 임의 근무지를 열고 cycle 패턴 문자열을 새 표현으로 수정한다.
- 저장 후 같은 근무지를 다시 열어 동일 문자열이 그대로 표시되는지 확인한다.

### 3. 기존 데이터 fallback
- `pattern_string`이 없는 기존 cycle 데이터를 하나 확인한다.
- 상세/수정 화면에서 fallback 문자열이 보이는지, 수정 후 저장하면 이후에는 원문 문자열이 유지되는지 확인한다.

### 4. 기본 운영 복원
- JSON 백업 파일로 복원을 수행한다.
- Access DB 복원을 수행한다.
- 복원 후 인력 / 근무지 / 패턴 데이터가 정상 조회되는지 확인한다.

### 5. 설치본 smoke
- packaged 실행 파일로 로그인과 핵심 화면 진입을 확인한다.
- installer 재설치 경로에서 기존 설치 덮어쓰기가 정상 동작하는지 확인한다.
