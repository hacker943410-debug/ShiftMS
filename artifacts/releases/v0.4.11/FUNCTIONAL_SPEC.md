# v0.4.11 기능 명세

## 실적관리 조회구분
- 사용자는 `승인대기` 또는 `승인완료 보관본` 중 하나만 선택할 수 있다.
- `전체` 조회구분은 제공하지 않는다.
- 기본 조회구분은 `승인대기`다.

## 승인완료 보관본 조회
- 승인완료 보관본은 연도와 월이 모두 선택된 경우에만 조회한다.
- 연도/월이 없는 요청은 전체 폴더를 스캔하지 않고 안내 메시지를 반환한다.
- 승인완료 월 조회는 `approvedDir/YYYY년/M월` 범위만 확인한다.

## 승인대기 표시 기준
- 승인대기 실적 행은 실제 파일이 `pendingDir` 내부에 존재할 때만 표시한다.
- 파일이 삭제되거나 승인대기 폴더 밖으로 이동된 DB 행은 목록에 표시하지 않는다.
- 월별 승인대기 동기화 후 해당 월에 존재하지 않는 pending DB 행은 정리 대상이다.

## 재승인 후보
- 승인완료 월 조회에서도 같은 월의 승인대기 재진입 파일은 재승인 후보 요약으로 유지한다.
- 이때 확인 범위는 선택한 월의 승인대기 폴더로 제한한다.
