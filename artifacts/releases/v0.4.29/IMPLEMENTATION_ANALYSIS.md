# Implementation Analysis

## 실적 재승인
- `performance-file-intake-service`에서 승인대기 파일을 다시 파싱할 때 기존 저장본이 승인완료인지 확인한다.
- 단순 재배치 파일은 기존 승인본으로 유지한다.
- 연결된 최신 수당 산출 결과가 `rejected`이면 수당 반려 후 복귀로 판단해 파일 상태를 `rejected`로 저장한다.
- 이 상태는 실적 overview의 재승인 파일 요약과 재승인 버튼 조건을 정상적으로 활성화한다.

## 반복 사이클
- 기존 테스트는 1회 반려 후 재승인만 검증했다.
- 새 테스트는 수당 승인, 근무지 반려, 재승인, 승인완료 이동을 두 번 반복한다.
- 법정휴일 행이 계속 목록에 남고 재승인 가능한지 확인한다.

## 시작/메뉴
- 업데이트 확인은 시작 직후가 아니라 지연 타이머로 실행한다.
- 파일 감시와 실적 복구도 BrowserWindow 생성 후 백그라운드로 시작한다.
- 데스크톱 폭에서는 `.console-shell` 2컬럼 레이아웃을 유지하고, 모바일 폭에서만 단일 컬럼으로 전환한다.
