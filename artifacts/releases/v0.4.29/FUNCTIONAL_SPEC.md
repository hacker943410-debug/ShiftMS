# Functional Spec

## 실적 재승인 복구
- 승인대기 폴더에서 발견된 파일의 기존 DB 상태가 승인완료여도 즉시 재승인을 요구하지 않는다.
- 동일 파일의 최신 수당 산출 결과가 반려 상태이면 재승인 대상 파일로 표시한다.
- 재승인 대상 파일은 법정휴일, 연장, 대체 실적 행을 모두 현재 파일 기준으로 다시 승인할 수 있다.
- 모든 대상 행이 재승인되면 승인완료 폴더로 이동하고 최신 유효 파일로 지정한다.

## 시작속도
- 앱 창 생성 전에는 필수 초기화만 수행한다.
- 업데이트 확인, 파일 감시, 실적 복구는 창 생성 후 지연 실행한다.
- 사용자는 시작 직후 update 상태가 비어 있어도 메뉴 조작을 먼저 할 수 있다.

## 메뉴와 실적 표시
- 데스크톱 폭에서는 좌측 메뉴가 고정된 사이드바로 표시된다.
- 모바일 폭에서만 메뉴가 단일 컬럼으로 전환된다.
- 실적관리 조별 소계는 실제 조 이름을 표시하고 날짜 우선 정렬을 유지한다.
