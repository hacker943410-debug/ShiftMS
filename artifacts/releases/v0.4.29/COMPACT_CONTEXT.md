# Compact Context

## 요청
- 수당 반려 후 승인완료 파일이 승인대기에 있는데 법정휴일 실적이 로드되지 않는 문제를 해결한다.
- 재승인 버튼이 동작하지 않는 원인을 고친다.
- 시작이 느린 문제와 메뉴/로고 레이아웃 이상을 포함해 패키징한다.

## 원인
- 승인완료로 저장된 동일 파일이 승인대기 폴더에 다시 나타났을 때, 수당 반려 이력을 확인하지 않아 기존 승인본으로 오판했다.
- 이 상태에서는 행이 `approved`로 표시되어 `approvePendingFile` 호출이 중복 승인으로 차단됐다.
- 자동 업데이트 확인과 파일 감시/실적 복구 작업이 초기 실행 시점에 몰려 창 표시가 늦어졌다.
- 1280px breakpoint가 데스크톱에서도 콘솔 셸을 단일 컬럼으로 바꿨다.

## 조치
- 수당 반려 이력이 있는 승인완료 파일이 승인대기에 재진입하면 `rejected` 재승인 사이클로 전환.
- 법정휴일 재승인과 반복 반려/재승인 회귀 테스트 추가.
- 시작 백그라운드 작업을 창 표시 이후로 지연.
- 모바일 레이아웃 전환 폭을 760px로 제한하고 로고 최대 크기 지정.
