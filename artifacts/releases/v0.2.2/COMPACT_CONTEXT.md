# v0.2.2 Compact Context

## 한 줄 목표
- 공통 셸과 활동 이력, PDF 양식, 실적 관리 행 처리 규칙을 함께 정리한다.

## 현재 범위
- 우측 상단 내 정보 모달과 활동 이력 메뉴를 추가한다.
- 인력 관리, 운영 관리, 수당 관리의 화면/필터 사용성을 보정한다.
- 별첨 PDF와 실적 승인완료 목록 숨김, 독립 연장근무 수당 계산 복구를 반영한다.

## 구현/운영 원칙
- renderer는 UI와 안내만 담당하고, 파일/DB/문서 처리는 main/preload를 통해서만 수행한다.
- 계산, 승인, 이력, 출력 규칙은 shared 또는 main service에 둔다.
- 조용한 덮어쓰기보다 이력 기반 재현성과 운영자 확인을 우선한다.
