# v0.2.2 작업 폴더

## 목적
- 이 폴더는 v0.2.2 패치/릴리즈의 분석, 구현, QA, 결과 문서를 한 위치에서 관리한다.

## 현재 상태
- 기준일: 2026-03-31
- 성격: 공통 셸, 활동 이력, PDF/실적 흐름 보강
- 상태: 패치 구현 및 자동 검증 완료

## 문서 구성
- COMPACT_CONTEXT.md: 이번 버전의 목표와 범위를 압축 정리한다.
- IMPLEMENTATION_ANALYSIS.md: 구현 배경, 제약, 설계 방향을 요약한다.
- FILE_IMPACT.md: 핵심 변경 영역을 경로 단위로 정리한다.
- FUNCTIONAL_SPEC.md: 사용자 관점 동작과 검증 포인트를 정리한다.
- TODO.md: 구현/검증 단계를 체크리스트로 남긴다.
- QA_CHECKLIST.md: 자동 검증과 수동 확인 기준을 기록한다.
- RESULT_REPORT.md: 최종 결과와 남은 이슈를 정리한다.

- 공통 셸과 활동 이력, PDF 양식, 실적 승인완료 목록 정책을 한 패치로 정리했다.
- 독립 연장근무 계산 오류를 복구해 기존 승인/수당 이력까지 보정했다.
