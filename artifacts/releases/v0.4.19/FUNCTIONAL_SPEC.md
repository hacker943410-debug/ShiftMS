# v0.4.19 Functional Spec

## 근무지 수정
- 저장된 근무 코드가 `A,C,B`처럼 섞여 있어도 화면의 1근, 2근, 3근 시간 카드는 canonical 슬롯 순서로 표시한다.
- 보라매DC 기준 기대값은 `1근 09:00-15:00`, `2근 15:00-21:00`, `3근 21:00-09:00`이다.
- 슬롯별 휴게시간은 각각의 근무에 맞게 저장한다.

## 실적 추출 영향
- 실적 추출은 저장된 월간 근무표의 시간을 그대로 계산한다.
- 이번 패치는 잘못된 근무지 수정 저장으로 월간 근무표 시간이 오염되는 경로를 차단한다.

## 품의서 Excel 출력
- 병합 충돌이 발생하면 기능명과 셀 범위를 포함한 메시지를 표시한다.
- 고객사 요약 병합은 동일 고객사 세로 병합 전에 기존 행 단위 병합을 정리한다.
- 별첨1 헤더와 수당 요율 안내 병합도 동일한 진단 메시지 체계를 사용한다.
