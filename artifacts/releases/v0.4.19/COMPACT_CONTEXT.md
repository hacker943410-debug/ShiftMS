# v0.4.19 Compact Context

## 배경
- 보라매DC에서 근무지 수정 1단계의 2근/3근 시간이 저장 화면과 다르게 보이고, 이후 실적 추출 기준 시간이 잘못될 수 있는 문제가 확인됐다.
- 품의승인 이후 Excel 출력에서 `Cannot Merge already merged cells` 오류가 발생했지만, 기존 메시지로는 어떤 영역의 병합 충돌인지 추적하기 어려웠다.

## 핵심 원인
- 패턴 step 최초 등장 순서와 canonical 근무 슬롯 순서가 다른 경우, 수정 draft 시간이 `A,C,B` 순서로 만들어졌다.
- 품의서 고객사 요약 영역은 행 단위 병합 후 동일 고객사 세로 병합을 다시 수행하므로 기존 병합 정리가 부족하면 충돌한다.

## 해결 방향
- 근무지 수정 draft 시간과 휴게시간을 `A/B/C`, `D/N` canonical 슬롯 기준으로 생성한다.
- Excel 병합 호출을 진단 helper로 감싸 문서 기능, 처리 구간, 대상 범위, 기존 병합 범위를 포함한 오류를 제공한다.
