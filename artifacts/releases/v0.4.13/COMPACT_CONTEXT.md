# v0.4.13 Compact Context

## 핵심
- 버전: `0.4.13`
- 목적: 품의서/별첨 출력 안정화, 수당 계산 보정, DB복원 기본값, BP 필터, 품의서 문서번호 보정

## 변경 포인트
- 문서 출력 경로: `기준폴더\YYYY년\MM월\YYYY_MM_문서명.xlsx/pdf`
- 최종품의수당: 총수당 합계 후 `Math.ceil`
- 별첨1: Blank 필수 셀 방지, 연장근무는 연장근로수당으로 표시
- DB복원: 공백/미분류 상태는 `재직`
- 인력관리: `전체 / BP / BP 제외` 필터
- 품의서 문서번호: 문서일자 월 기준 `YYYY-MM`
