# v0.4.13 결과 보고

## 완료 항목
- 품의서/별첨1/별첨2 Excel/PDF 출력 경로를 월별 표준 폴더 구조로 통일했다.
- 품의서/별첨 문서의 최종품의수당을 원 단위 올림 기준으로 반영했다.
- 별첨1 생성 시 필수 행 데이터가 빈칸으로 출력되는 문제를 보정했다.
- 연장근무 실적이 기본근로수당으로 분류되는 문제를 연장근로수당 기준으로 수정했다.
- DB복원 시 인력 상태 기본값을 `재직`으로 변경했다.
- 인력관리 BP 필터와 필터 기준 인원 수 표시를 추가했다.
- 문서 출력 실패 시 내부 모달 안내를 보강했다.
- 품의서 Excel/PDF 문서번호를 문서일자 기준 월로 출력하도록 수정했다.

## 검증 결과
- 문서번호/문서 출력 관련 단위 테스트 통과
- TypeScript 타입 검사 통과
- `npm run test` 통과: 122개 파일, 529개 테스트
- `npm run build` 통과
- 릴리즈 게시 검증은 배포 단계에서 실행한다.

## 수동 확인 권장
- 실제 운영 양식으로 품의서, 별첨1, 별첨2 Excel/PDF가 지정 폴더 아래 생성되는지 확인
- 연장근무만 있는 실적이 별첨1에서 연장근로수당으로 표시되는지 확인
- Access/JSON 복원 후 상태 공백 인력이 `재직`으로 보이는지 확인
- 인력관리 BP 필터 결과와 인원 수가 실제 데이터와 일치하는지 확인
