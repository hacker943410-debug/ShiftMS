# v0.4.13 기능 명세

## 문서 출력 경로
- 사용자가 지정한 폴더는 최종 파일 폴더가 아니라 문서 종류별 기준 폴더로 해석한다.
- 실제 파일은 `기준폴더\YYYY년\MM월\YYYY_MM_문서명.xlsx/pdf`로 생성한다.
- 중복 파일명은 기존 중복 방지 규칙을 따른다.

## 수당 계산
- 기본 계산식은 `시급 * 요율 * 근로시간 = 총수당`이다.
- 문서에 반영되는 최종품의수당은 모든 총수당 합계에 원 단위 올림을 적용한다.
- 연장근무 실적은 기본근로수당이 아니라 연장근로수당으로 분류한다.

## 별첨1
- 순번, 근무지, 직원명, 근무일, 근무구분, 근무시간, 수당금액은 빈칸으로 남기지 않는다.
- 대상이 아닌 시간/금액 칸은 `-`로 표시한다.

## DB복원
- 인력 상태가 공백, 미분류, 알 수 없는 값이면 `재직`으로 저장한다.
- 명확한 퇴사/휴직 값은 각각 퇴사/휴직으로 저장한다.

## 인력관리
- 고용형태 필터는 `전체 / BP / BP 제외`를 제공한다.
- 화면에는 현재 필터 기준 인원 수와 전체 인원 수를 함께 표시한다.

## 품의서 문서번호
- 품의서 Excel/PDF 문서번호는 문서일자에 표시된 월 기준 `YYYY-MM`으로 출력한다.
- 문서일자를 해석할 수 없으면 기존 집행월 값을 fallback으로 사용한다.
