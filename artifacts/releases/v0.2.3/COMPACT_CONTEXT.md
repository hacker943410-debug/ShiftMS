# v0.2.3 Compact Context

## 한 줄 목표
- 별첨1 PDF 레이아웃 안정성과 활동 이력 감사 해석성을 높인다.

## 현재 범위
- 별첨1 PDF의 표 폭, 유형 라벨, 소계/총소계 표현을 재정리한다.
- 운영 관리 접속 이력을 활동 이력으로 개명하고 필터/액션 체계를 확장한다.
- 주요 성공 기록을 renderer가 아니라 main IPC 성공 지점 기준으로 남긴다.

## 구현/운영 원칙
- renderer는 UI와 안내만 담당하고, 파일/DB/문서 처리는 main/preload를 통해서만 수행한다.
- 계산, 승인, 이력, 출력 규칙은 shared 또는 main service에 둔다.
- 조용한 덮어쓰기보다 이력 기반 재현성과 운영자 확인을 우선한다.
