# v0.4.12 기능 명세

## 1. Pool 대체근무 판정
- 근무대체자 값이 `이름(P)`이면 Pool 대체근무로 판정한다.
- 대체근무 행의 등록 인력이 현재 `Pool` 근무조이면 Pool 대체근무로 판정한다.
- `(P)`는 대소문자와 공백 차이를 허용한다.

## 2. 실적 저장
- 직원명은 `(P)`를 제거한 실제 이름으로 저장한다.
- 원본 표기는 비고에 `원본 표기 이름(P)` 형태로 남긴다.
- 비고에 `Pool 대체근무`, `수당 미지급`을 함께 남긴다.
- 등록 인력 정보가 없어도 `(P)` 표기 Pool 대체근무는 경고로 남기고 실적 행은 유지한다.

## 3. 승인/수당 처리
- Pool 대체근무는 승인 가능 건수에 포함하지 않는다.
- Pool 대체근무는 수당 계산과 품의 반영 대상에서 제외한다.
- Pool 대체근무는 시급이 없어도 시급미반영항목으로 분류하지 않는다.

## 4. 실적관리 화면
- Pool 대체근무 행은 `수당 미지급` 상태로 표시한다.
- 근무예정자와 근무대체자 컬럼은 가운데 정렬한다.
- 행 우측의 정보 버튼을 누르면 인력 기본정보와 시급 이력 모달을 표시한다.
- 정보 모달은 근무지, 조이름, 고용형태, 상태, 배정기간, 현재시급, 근무일 적용시급을 보여준다.
