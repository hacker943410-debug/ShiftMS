# v0.4.12 Compact Context

## 목표
Pool 인력이 대체근무자로 들어온 실적은 운영 이력으로 남겨야 하지만 수당은 지급하지 않는 기준을 프로그램에 반영한다.

## 확정 기준
- 실적 파일에서 근무대체자 이름 끝에 `(P)`가 붙으면 Pool 대체근무로 본다.
- 등록 인력의 현재 근무조가 `Pool`인 직원이 대체근무 행에 들어온 경우도 Pool 대체근무로 본다.
- Pool 대체근무는 실적 목록과 상세 정보에 남긴다.
- Pool 대체근무는 승인 가능 행, 수당 산정 행, 시급미반영항목에서 제외한다.
- `(P)` 표기는 저장 시 직원명에서 제거하고, 원본 표기는 비고에 남긴다.

## 검증 초점
- `(P)` suffix 파싱
- Pool 대체근무 행 보존
- 수당 승인 대상 제외
- 실적관리 정보 모달 표시
- 근무예정자/근무대체자 중앙 정렬
