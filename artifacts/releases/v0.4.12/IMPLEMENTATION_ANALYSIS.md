# v0.4.12 구현 분석

## 문제
기존 기준에서는 Pool 대체근무를 실적 파싱 또는 수당 흐름에서 제외하면 현장 운영 이력까지 사라질 수 있었다. 반대로 일반 대체근무와 동일하게 승인하면 지급 대상이 아닌 Pool 투입 건이 수당 산정에 포함될 수 있었다.

## 해결 방향
- 파서에서 `이름(P)`를 직원명과 Pool 표식으로 분리한다.
- 실적 행은 유지하되 `isPoolWorker=true`, 비고 `Pool 대체근무 / 수당 미지급`을 저장한다.
- 실적관리 overview는 Pool 대체근무 행을 숨기지 않고 `non-payable` 상태로 보여준다.
- 승인 가능 여부와 재승인 비교, 시급미반영 분류에서는 Pool 대체근무를 제외한다.
- renderer는 정보 버튼을 통해 해당 행의 등록 인력과 근무일 기준 시급 이력을 확인할 수 있게 한다.

## UI 기준
- 실적 목록에서 사용자가 Pool 대체근무 행을 확인할 수 있어야 한다.
- 승인 버튼은 제공하지 않고 `Pool 대체근무 수당 미지급` 안내를 표시한다.
- 인력/시급 정보 모달은 등록 인력 정보가 없을 때도 실적 파일 기준 정보와 오류 안내를 보여준다.
