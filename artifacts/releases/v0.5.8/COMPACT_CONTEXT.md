# v0.5.8 Compact Context

## 목표

0.5.7 이후 누적된 인력·시급·승인·설치 데이터 안전성 수정을 하나의 검증 가능한 릴리즈로 게시한다.

## 확정 불변식

- 승인 완료 실적과 승인 당시 금액은 시급 변경으로 소급 수정하지 않는다.
- 최신 재분석에 실패한 승인대기 파일은 이전 분석 행이 남아 있어도 승인하지 않는다.
- 시급 삭제는 삭제 전 상태와 작업자를 영구 이력에 남기지 못하면 실행하지 않는다.
- 같은 시작일 시급 삭제로 다른 금액이 드러나면 운영자 확인값과 서버 판정이 일치해야 한다.
- renderer에는 근무표 작성에 필요한 최소 직원 정보만 노출한다.
- 설치 업데이트는 판정하지 못한 사용자 파일을 삭제하거나 덮어쓰지 않고 안전하게 실패한다.

## 비목표

- 승인 완료 금액의 자동 소급 재계산
- 외부 계정/VM이 필요한 G29 Hyper-V 검증
- 새 의존성 또는 네이티브 모듈 추가
