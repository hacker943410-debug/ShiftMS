# v0.5.8 기능 명세

## 시급 이력

- 새 시급 적용일은 빈칸으로 열리고 유효 날짜를 선택해야 저장할 수 있다.
- 이력은 시작일·종료일·금액·사유·문제·관리 열의 표로 표시한다.
- 정정은 대상 ID의 금액과 사유만 바꾸며 적용일은 유지한다.
- 삭제는 1~200자 사유가 필요하고 이웃 구간을 자동 확장하지 않는다.
- 같은 시작일의 이전 행이 다시 사용되면 정확한 금액을 경고하고 확인한 행 ID가 바뀌면 거절한다.
- 삭제 전 상태, 사유, 작업자, 시각은 감사 이력에 남는다.

## 승인대기 재분석

- 설정 변경 뒤 파싱을 시작할 때 현재 재분석 토큰을 파일 분석본에 저장한다.
- 파일 읽기나 DB 저장이 실패하면 기존 분석본은 보존하지만 승인에는 사용할 수 없다.
- 재분석에 성공한 뒤에만 승인할 수 있다.
- 이미 승인된 실적과 계산 스냅샷은 변경하지 않는다.

## 근무표용 직원 조회

- 호출자는 삭제 인력 포함 여부를 선택하지 않는다.
- main은 대상 월의 역사 배정을 내부 조회한다.
- renderer에는 사번·이름·고용형태·고용기간·대상 배정 등 편성에 필요한 값만 반환한다.
- 연락처, 직급, 시급, 삭제 시각, 감사 시각은 반환하지 않는다.
