# Functional Spec

## 실적관리 정렬
- 근무지별 실적 행은 근무일자 오름차순으로 먼저 표시한다.
- 같은 근무일자 안에서는 조 라벨 오름차순으로 정렬한다.
- 같은 날짜와 조 안에서는 근로유형, 직원명, 수신시각 순으로 정렬한다.

## 조 라벨 복원
- 저장된 실적 행에 `teamLabel`이 있으면 그대로 사용한다.
- 누락된 경우 월근무표의 같은 월, 근무지, 일자, 사원번호/이름으로 조를 찾는다.
- 대체근무는 실적 직원이 아니라 메모의 원근무자를 우선 사용한다.
- 그래도 찾지 못하면 인력 배정 이력 또는 현재 조 정보를 사용한다.

## 화면 묶음
- 조 요약 행은 `근무일자 + 조` 단위로 표시한다.
- 요약 행에는 실적, 승인, 대기, 반려, 재검토, 알림 건수를 표시한다.

## 메뉴 화면
- 메뉴 클릭 시 별도 route chunk를 동적으로 불러오지 않는다.
- 패치 후 asset hash 혼재로 화면 모듈 파일을 찾지 못하는 경로를 제거한다.
