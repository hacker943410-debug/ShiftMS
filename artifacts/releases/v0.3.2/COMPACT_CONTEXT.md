# v0.3.2 Compact Context

## 한 줄 목표
- 양식 관리 화면을 사용자 친화적으로 전면 개편해, 운영자가 도식 위에서 직접 문서 영역과 스타일을 수정할 수 있게 만든다.

## 현재 범위
- 양식 관리 UI 용어를 운영자 언어로 재정의한다.
- 파일 미리보기 중심 구조를 앱 내부 도식형 미리보기 구조로 전환한다.
- 근무표/품의서/별첨1/별첨2를 템플릿 종류별 시맨틱 영역으로 모델링한다.
- 셀 너비/높이/폰트/배경색/정렬/병합을 `style spec` 으로 저장하고 출력에 반영할 준비를 한다.
- 후속 보강으로 대시보드 `기간 직접 지정` 월 선택 UI를 앱 공통 팝오버 톤으로 맞추고, 운영 관리 `사이트 명 관리` 가이드를 추가한다.

## 비목표
- 이번 단계에서 완전한 엑셀 편집기 자체를 구현하지 않는다.
- 외부 상용 그리드 라이브러리 도입을 전제로 설계하지 않는다.
- 기존 출력/배포/품의 승인 기능을 대체하지 않고 양식 관리부터 단계적으로 바꾼다.

## 확정 결정
- 현재 코드 버전 `0.3.1` 은 마감 상태로 유지하고, 이번 개편은 `v0.3.2` 작업 폴더 기준으로 진행한다.
- 새 의존성은 당장 추가하지 않고 `ExcelJS + 도식형 캔버스 편집기` 조합을 우선한다.
- 기본 모드는 의미 단위 편집, 고급 모드는 셀 단위 보정으로 분리한다.
- 파일 출력형 미리보기는 최종 검증용으로만 남기고, 일상 편집은 앱 내부 미리보기로 바꾼다.

## 우선순위
1. 용어/프로필 재정의
2. 도식형 미리보기 엔진
3. 직접 편집 + 속성 패널
4. 출력 스타일 규격화와 회귀 검증
5. 후속 UI/가이드 문서 정합성 유지
