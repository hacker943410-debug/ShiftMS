## 문서 구성
- COMPACT_CONTEXT.md: 이번 버전의 목표와 범위를 압축 정리한다.
- IMPLEMENTATION_ANALYSIS.md: 현재 구조, 제약, 기술 선택 근거를 정리한다.
- FILE_IMPACT.md: 수정/생성 예상 파일을 경로 단위로 정리한다.
- FUNCTIONAL_SPEC.md: 사용자 흐름과 화면/입출력 요구사항을 정리한다.
- TODO.md: 구현 순서와 세부 작업 항목을 정리한다.
- QA_CHECKLIST.md: 구현 후 확인할 자동/수동 검증 기준이다.
- RESULT_REPORT.md: 구현 완료 후 결과와 잔여 이슈를 기록한다.
- SCENARIO_TEST_PLAN.md: 빈 DB 기준 실제 운영 시나리오 테스트 3개와 초기화 상태를 기록한다.

## 이번 버전 요약
- 양식 관리를 `셀 좌표 보정` 중심에서 `문서 영역 조정` 중심으로 바꾼다.
- 근무표, 품의서, 별첨1, 별첨2를 도식형 프리뷰와 의미 단위 편집으로 통일한다.
- 셀 너비, 높이, 폰트, 배경색, 정렬, 병합을 `style spec` 으로 관리 가능한 기반을 만든다.
- 현재는 선택 영역 속성 편집, 고급 모드 셀 선택, 병합 범위 편집, 행/열 빠른 직접 조절, 출력 workbook 반영, 통합 smoke, 운영 문서/가이드 갱신까지 연결됐다.
- 후속 보강으로 대시보드 `기간 직접 지정` 월 선택 UI를 앱 공통 팝오버 톤으로 맞추고, 운영 관리 `사이트 명 관리` 가이드를 추가했다.
- 저장 구조 마감, 승인/기본 사용 전환 회귀 확인, 수동 QA 정리가 남아 있다.
