# v0.3.2 기능 명세

## 1. 사용자 목표

운영자는 엑셀 셀 주소를 몰라도 아래를 할 수 있어야 한다.

1. 근무표/품의서/별첨1/별첨2의 주요 문서 영역을 이해한다.
2. 화면 위 도식을 클릭해 위치와 스타일을 수정한다.
3. 앱 내부 미리보기로 결과를 즉시 확인한다.
4. 필요하면 고급 모드에서 세부 셀 단위 보정을 한다.
5. 저장 후 실제 출력 파일에서 같은 결과가 재현되는지 검증한다.

## 2. 공통 사용자 흐름

1. 양식 종류 선택
2. 파일 Import
3. 자동 구조 분석
4. 앱 내부 도식 미리보기 확인
5. 영역 클릭
6. 우측 속성 패널에서 수정
7. 샘플 데이터 on/off 확인
8. 저장
9. Excel 검증 출력
10. 승인 / 기본 사용 전환

## 3. 기본 화면 요구사항

### 상단 요약
- 양식 종류
- 현재 버전
- 승인 상태
- 기본 사용 여부
- 검증 상태
- 최근 수정일

### 좌측 도식 편집 영역
- 실제 문서 형태를 축소한 캔버스
- 시맨틱 영역 하이라이트
- 샘플 데이터 반영 on/off
- 확대/축소
- 기본/고급 모드 전환

### 우측 속성 패널
- 현재 선택 영역 이름
- 영역 설명
- 수정 가능한 속성 목록
- 변경 전/후 값
- 리셋 버튼

## 6. 저장/검증 규칙

1. 변경 저장 전 내부 유효성 검사를 수행한다.
2. 영역이 겹치거나 필수 영역이 사라지면 저장을 막는다.
3. 승인된 기본 양식은 직접 덮어쓰지 않고 새 버전으로 저장한다.
4. 저장 후 `Excel 검증 출력` 으로 실제 workbook 반영 여부를 확인할 수 있어야 한다.

## 7. 예외 처리

1. 자동 구조 분석 실패 시 사용자 언어로 이유를 보여준다.
2. 감지되지 않은 영역은 `직접 지정` 으로 전환 가능해야 한다.
3. 기존 `generic` 프로필은 migration 후 새 구조로 읽어야 한다.

## 8. 후속 UI/가이드 보강

1. 대시보드 `기간 직접 지정`의 `시작 월`, `종료 월`은 브라우저 기본 month picker가 아니라 앱 공통 팝오버 톤의 월 선택 UI를 사용한다.
2. 운영 관리 가이드에는 `사이트 명 관리` 페이지를 포함해 사이트 명 추가, 사용 근무지 확인, 수정/삭제 제한 흐름을 안내한다.
3. `사이트 명 관리` 가이드 장면은 운영 관리 탭 구조 안에서 사이트 명 목록과 행 단위 작업을 보여준다.
