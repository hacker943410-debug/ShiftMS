# Functional Spec

## 근무지 관리 상세 보기
- Given 근무 패턴이 `A, C, B` 순서로 저장되어도
- When 근무지 상세 Cycle 근무시간을 볼 때
- Then 화면에는 `A 1근`, `B 2근`, `C 3근` 순서로 표시한다.

## 실적관리 새로고침
- Given 반환 파일 자체는 변경되지 않았지만 저장된 월근무표 시간이 수정된 상태에서
- When 실적관리 새로고침 버튼을 클릭하면
- Then 반환 파일을 다시 파싱하고 최신 월근무표 시간으로 총근무/연장 시간을 재계산한다.

## `None` 실적 제외
- Given 근무표 또는 반환 근무표의 실투입자/대체자/근무자 칸에 `None`이 입력되어 있으면
- When 실적관리에서 반환 파일을 파싱할 때
- Then 해당 칸은 법정휴일, 대체, 연장 실적 대상에서 제외하고 목록에도 표시하지 않는다.

## 실적관리 필터와 테이블
- 필터 순서는 `연도`, `월`, `근무지명`, `조회구분`, `근로유형`으로 표시한다.
- 각 필터 박스 폭은 기존 값과 동일하게 유지한다.
- 데스크톱에서는 실적 테이블 밀도를 높여 좌우 스크롤 발생을 줄인다.
- 좁은 화면에서는 가독성을 위해 가로 스크롤 fallback을 유지한다.

## 품의서 템플릿 등록
- Given 운영자가 품의서 템플릿을 등록할 때
- When 템플릿의 주요 anchor row가 구형 배치로 판정되면
- Then 저장을 차단하고 신형 템플릿을 사용하라는 안내를 표시한다.
- 신형 배치는 저장 가능하며, 알 수 없는 배치는 경고 후 저장 가능 상태로 유지한다.
