# v0.4.4 기능 범위

## DB 복원
- Access 복원 실패 시 PowerShell/스크립트 원인을 더 세분화해 표시한다.
- 복원에 필요한 기본 리소스 경로를 설치본에서도 안정적으로 찾는다.

## 문서 출력
- 기본 품의서/별첨/근무표 양식은 설치본 내부 리소스를 fallback 으로 사용한다.
- 품의서의 근무지명 좌측에는 등록된 사이트 명을 우선 표시한다.
- 사이트명은 공백/기호 차이가 있어도 동일 근무지면 연결한다.

## 공통 UX
- 주요 저장/승인/적용 액션은 내부 모달로 결과를 안내하고 활동 이력에 남긴다.
