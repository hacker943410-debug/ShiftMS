# v0.4.9 Compact Context

## 배경
- 기존 로그인 정책은 5회 실패 시 15분 잠금이며, 비밀번호 해시는 복구할 수 없다.
- admin과 사용자 계정 모두 비밀번호를 잊은 경우 0.4.8 UI만으로는 복구할 수 없다.

## 결정
- 로그인 화면에 계정복구 버튼을 둔다.
- 복구는 사전에 발급한 계정복구키가 있어야만 가능하다.
- 복구키 원문은 1회만 표시하고 DB에는 scrypt 해시만 저장한다.
- 복구 전 SQLite DB를 로컬 백업한 뒤 admin 임시 비밀번호를 발급한다.
- 복구키 미발급 기존 설치본은 유지보수 스크립트로 대응한다.
