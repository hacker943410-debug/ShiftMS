# v0.4.9 구현 분석

## 인증 저장소
- `app_users`에 복구키 해시, 발급일, 실패 횟수, 잠금 시각 컬럼을 추가했다.
- 기존 DB는 앱 시작 시 `ensureColumn`으로 forward-only 마이그레이션된다.

## 복구 서비스
- `account-recovery-service`가 복구키 발급, 복구 가능 여부 조회, admin 계정 복구를 담당한다.
- 복구 성공 시 DB 파일을 `account-recovery-backups`에 복사한 뒤 비밀번호를 임시값으로 교체한다.
- 임시 비밀번호는 강한 비밀번호 규칙을 만족하고 `must_change_password=1`로 저장된다.

## UI
- 로그인 화면 계정복구 모달은 복구키 입력, 결과 안내, 미발급 안내를 모두 처리한다.
- 운영 관리 사용자 관리에는 계정복구키 발급 액션과 1회 표시 모달을 추가했다.
