# v0.4.9 기능 명세

## 계정복구키 발급
- 위치: `운영 관리 > 사용자 관리`
- 권한: admin 권한 필요
- 동작:
  - 새 복구키를 발급하면 기존 복구키는 무효화된다.
  - 발급된 키는 모달에 1회만 표시된다.
  - DB에는 복구키 해시와 발급일만 저장한다.
  - 활동 이력에 `계정복구키 발급`을 기록한다.

## 로그인 화면 계정복구
- 위치: 로그인 화면 `계정복구`
- 조건:
  - 복구키가 발급되어 있어야 한다.
  - 복구키 입력 5회 실패 시 15분 잠금된다.
- 성공 처리:
  - 복구 전 DB 파일을 백업한다.
  - admin 계정을 `active` 상태로 보정한다.
  - 로그인 실패 횟수와 잠금 시간을 초기화한다.
  - 임시 비밀번호를 발급하고 다음 로그인 시 변경을 강제한다.
  - 활동 이력에 `계정 복구`를 기록한다.

## 유지보수 스크립트
- 파일: `scripts/reset-admin-password.mjs`
- 목적: 복구키가 발급되기 전 이미 잠긴 기존 설치본 대응
- 실행 예:
  - `node scripts/reset-admin-password.mjs --db C:\Users\<user>\AppData\Roaming\ShiftMgmt\data\shiftmgmt.sqlite`
- 동작:
  - DB 백업 생성
  - admin 임시 비밀번호 발급
  - 잠금/실패 횟수 초기화
