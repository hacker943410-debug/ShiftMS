# v0.3.0 Compact Context

## 한 줄 목표
- 실적 승인, 수당 승인, 품의 승인, 백업 흐름을 실무 기준으로 다시 연결한다.

## 현재 범위
- 재승인 파일과 승인완료 보관본 조회 기준을 정리한다.
- 수당 계산 결과에 검토대기/승인/반려/품의승인 상태 흐름을 도입한다.
- 품의 승인 미리보기, 최종 승인, 자동 백업, 품의 이력까지 한 흐름으로 연결한다.

## 구현/운영 원칙
- renderer는 UI와 안내만 담당하고, 파일/DB/문서 처리는 main/preload를 통해서만 수행한다.
- 계산, 승인, 이력, 출력 규칙은 shared 또는 main service에 둔다.
- 조용한 덮어쓰기보다 이력 기반 재현성과 운영자 확인을 우선한다.
