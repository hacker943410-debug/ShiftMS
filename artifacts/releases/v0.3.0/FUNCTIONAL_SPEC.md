# v0.3.0 기능 명세 요약

## 사용자 관점 동작
- 재승인 확정은 현재 파일의 변경 가능 행이 모두 현재 사이클 기준으로 다시 승인된 경우에만 허용한다.
- 수당 행은 검토대기/승인/반려/품의승인 상태와 이력을 append-only로 남긴다.
- 품의 승인 시 문서 출력, 승인 기록 저장, 상태 전환, DB 자동 백업을 같은 마감 흐름으로 처리한다.

## 검증 포인트
- 화면 동작과 저장 결과가 동일한 업무 의미를 유지해야 한다.
- 관련 이력과 출력/백업 산출물이 조용히 덮어써지지 않아야 한다.
- 운영자가 가이드/문서만으로 후속 조치를 판단할 수 있어야 한다.
