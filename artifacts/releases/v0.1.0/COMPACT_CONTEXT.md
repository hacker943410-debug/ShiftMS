# v0.1.0 Compact Context

## 한 줄 목표
- 교대근무 운영 핵심 흐름을 하나의 로컬 Electron 앱에서 실행 가능한 첫 설치형 릴리즈 기준선을 만든다.

## 현재 범위
- 인력 관리, 근무지 관리, 근무표 배포, 실적 관리, 수당 관리, 운영 관리의 기본 흐름을 연결한다.
- DB업데이트, 문서 출력, 설치본 패키징까지 포함한 첫 릴리즈 기준을 확정한다.
- 실데이터 수동 QA와 자동 검증 결과를 릴리즈 문서로 묶는다.

## 구현/운영 원칙
- renderer는 UI와 안내만 담당하고, 파일/DB/문서 처리는 main/preload를 통해서만 수행한다.
- 계산, 승인, 이력, 출력 규칙은 shared 또는 main service에 둔다.
- 조용한 덮어쓰기보다 이력 기반 재현성과 운영자 확인을 우선한다.
