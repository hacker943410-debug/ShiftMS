# v0.1.0 기능 명세 요약

## 사용자 관점 동작
- Windows NSIS 설치본과 win-unpacked 실행 기준을 공식 산출물로 정의한다.
- 실적 승인, 수당 계산, 품의 문서 출력, 운영 관리 기준정보 복원을 하나의 앱 흐름으로 연결한다.
- 운영 관리 DB업데이트는 Access 기준정보와 기본 승인/수당 이력 복원을 지원한다.

## 검증 포인트
- 화면 동작과 저장 결과가 동일한 업무 의미를 유지해야 한다.
- 관련 이력과 출력/백업 산출물이 조용히 덮어써지지 않아야 한다.
- 운영자가 가이드/문서만으로 후속 조치를 판단할 수 있어야 한다.
