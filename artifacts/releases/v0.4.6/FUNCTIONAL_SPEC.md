# Functional Spec

## 패치노트
1. 앱은 시작 시 마지막 확인 버전 이후의 릴리즈 매니페스트를 모두 조회한다.
2. 대상이 2건 이상이면 패치노트 모달은 버전별 `이전`, `다음` 이동을 제공한다.
3. 마지막 버전까지 확인해야 패치노트 완료 상태를 저장한다.

## 운영 관리 > 패치이력
1. 릴리즈 매니페스트 목록을 버전 내림차순으로 보여준다.
2. `업데이트 구분`, `적용 조건`, `검색어` 필터를 제공한다.
3. 검색은 공백, 구분자, 대소문자 차이를 무시하는 정규화 검색으로 동작한다.
4. 매니페스트의 표 데이터도 검색 대상에 포함한다.
