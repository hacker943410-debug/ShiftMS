# Functional Spec

## 자동업데이트 저장소
1. `0.4.7`부터 패키징된 앱은 GitHub 저장소 `hacker943410-debug/ShiftMS`를 자동업데이트 기준으로 사용한다.
2. 앱 내부 업데이트 확인, 릴리즈 매니페스트 다운로드, GitHub Release 게시 스크립트는 모두 같은 저장소를 참조해야 한다.

## 신규 설치본 기준선
1. 신규 배포용 설치 파일은 `ShiftMgmt-Setup-0.4.7-x64.exe`를 기준으로 한다.
2. 기존 `0.4.6` 이하 설치본은 저장소 기준이 다르므로 자동으로 `0.4.7`을 찾지 못할 수 있다.
3. 기존 사용자도 `0.4.7`을 한 번 수동 설치하면 이후부터는 새 저장소 기준 자동업데이트를 받는다.
