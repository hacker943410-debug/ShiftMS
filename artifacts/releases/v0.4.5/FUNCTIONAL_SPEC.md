# v0.4.5 기능 명세

## 자동업데이트
- 앱 시작 후 업데이트를 확인한다.
- 새 버전이 있으면 내부 모달에 버전, 핵심 변경, 다운로드 버튼을 표시한다.
- 다운로드 완료 후 재시작 적용 버튼을 제공한다.
- 업데이트 후 첫 실행 시 패치노트를 1회 표시한다.

## 인력 관리
- 신규 인력 고용형태에서 `BP`를 선택할 수 있다.
- BP는 사원번호/통상시급 없이 저장 가능하다.
- 일반 인력의 고용형태 기본 표시는 실제 저장 payload에도 반영된다.

## 근무지/근무표
- 근무조별 인력 순서를 위/아래 이동으로 조정한다.
- 저장된 순서는 근무표 배포 시뮬레이션과 배포 현황에 반영된다.

## DB 복원/문서 출력
- Access 복원 실패 원인 안내를 세분화한다.
- 기본 양식 fallback을 설치본 내부 리소스에서 찾을 수 있다.
- 품의서에는 등록된 사이트 명과 근무지명이 안정적으로 출력된다.
