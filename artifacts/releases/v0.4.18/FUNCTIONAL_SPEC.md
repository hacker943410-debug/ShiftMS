# v0.4.18 Functional Spec

## 목표
품의승인 완료 시 Excel 품의서, 별첨1, 별첨2 파일이 자동 생성되도록 한다.

## 포함
- 최종 품의승인 요청 형식을 Excel 출력으로 변경
- 품의승인 완료 안내 문구를 Excel 기준으로 변경
- 미리보기 제목을 문서 출력 공통 표현으로 변경
- 품의승인 Excel 경로와 별도 PDF/Excel 문서 출력 경로 타깃 검증

## 기대 동작
- 사용자가 `품의 승인` 모달에서 `최종 품의 승인`을 누르면 Excel 문서 3종이 지정 경로에 저장된다.
- 사용자가 상단 `PDF 출력`을 누르면 PDF 문서 3종이 지정 경로에 저장된다.
- 사용자가 상단 `Excel 출력`을 누르면 Excel 문서 3종이 지정 경로에 저장된다.

## 제외
- 운영 양식 파일 자체 수정
- 월마감/급여 잠금
- 인증/권한 정책 변경
