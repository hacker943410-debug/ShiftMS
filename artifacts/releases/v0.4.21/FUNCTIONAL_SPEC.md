# v0.4.21 Functional Spec

## 실적 파싱
- 법정휴일 변경표에서 `홍길동 -> 실투입자` 또는 `- -> 실투입자`로 입력된 슬롯은 실투입자 이름이 월근무표에 없어도 해당 슬롯의 `dutyCode` 시간을 사용한다.
- 대체근무 표에서 원근무자가 `-`이고 실투입자가 입력된 경우, 같은 날짜 변경표의 `- -> 실투입자` 슬롯을 찾아 대체근무 실적으로 생성한다.
- 대체근무 표에서 원근무자가 `홍길동`인 경우, 같은 날짜 변경표의 홍길동 슬롯을 찾아 대체근무 시간을 산출한다.
- 월근무표 자체가 없거나 해당 dutyCode 시간이 없으면 행은 유지하고 경고를 표시한다.

## 품의서 Excel 출력
- 정규 지급 요약 행이 템플릿 기본 행 수를 초과해도 선지급 지급 내역 헤더는 정규 요약 합계행 아래로 이동한다.
- 정규 요약 합계 병합 범위와 선지급 헤더 병합 범위는 서로 겹치지 않는다.
- 병합 충돌 발생 시 기존 진단 메시지 체계는 유지한다.
