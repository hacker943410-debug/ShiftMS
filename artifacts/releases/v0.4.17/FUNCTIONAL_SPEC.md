# v0.4.17 Functional Spec

## 목표
- `0.4.14` 소스 기준에서 `0.4.16` 배포 장애 수정과 승인된 `0.4.15` 안정화/기능 항목을 복구한다.
- 추가 패치는 사용자 의사결정 후 별도 단계로 진행한다.

## 포함
- 프로그램 시작 시 새 버전 존재 여부를 확인하고 다운로드 전에 업데이트 알림 표시
- 업데이트 알림 모달에서 표 기반 패치노트 표시
- 수당 원시 금액 합산 후 최종 1회 올림 계산
- 요율 영향 미리보기의 수당 계산 기준 동일화
- 승인 완료 파일 재대기 후 부분 승인 상태 재조회 검증
- 품의 승인 후 품의서/별첨 Excel 출력 검증
- 품의서/별첨 Excel 재출력 시 병합 셀 충돌 방지
- renderer root/route 오류 격리
- DB 교체 중단 후 orphan migration backup 복구
- 월 근무표 저장 실패 시 기존 저장 데이터 보호
- 운영 요율 매트릭스 빈 값 및 비정상 숫자 저장 방지
- 근무지 패턴 시작일 fallback과 day/night 표시 순서 안정화
- 근무패턴 반복 표현 회귀 방어
- 인력관리 하단 집계의 현재 필터 기준 계산
- 근무표 규칙 경고 표시
- 운영 설정의 근무표 경고 기준 저장
- 요율 저장 전 영향 미리보기
- 지급 대상 수당 라인 0원화 경고

## 제외
- 인증 bootstrap 정책 변경
- Electron navigation/window-open/CSP 제한
- 월마감/급여 잠금
- 패키징 및 GitHub Release 게시
