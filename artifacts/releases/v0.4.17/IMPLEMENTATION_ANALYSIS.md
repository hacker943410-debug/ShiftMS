# v0.4.17 Implementation Analysis

## 기준선
- 현재 브랜치: `release/0.4.17`
- 분기 기준: `release/0.4.14`
- 원격 소스 한계: `release/0.4.15`, `release/0.4.16` 부재
- 배포 이력 참고: GitHub Release `v0.4.15`, `v0.4.16` body

## 구현 기준
- 설치본의 컴파일 산출물을 역변환하지 않고, 공개 릴리즈 본문과 현재 소스 구조를 기준으로 TypeScript를 재구현했다.
- 사용자 승인 번호만 반영했다.
- 보안/인증 계층 변경은 현재 오류 원인과 충돌 가능성이 있어 제외했다.
- 회귀 가능성이 큰 기능은 공유 도메인 테스트를 먼저 추가하고 renderer에는 결과 표시만 연결했다.

## 핵심 설계
- Excel 병합 셀 정리는 `worksheet.model.merges`와 실제 셀 병합 상태를 함께 정리한다.
- 월 근무표 저장은 기존 데이터 삭제 전에 모든 직원 사번을 검증하고, 쓰기 작업을 하나의 트랜잭션으로 묶는다.
- DB orphan backup 복구는 DB 파일이 없고 migration backup만 남은 경우 최신 백업을 원래 DB 경로로 되돌린다.
- 근무표 경고는 배포 차단이 아니라 운영자 확인용 경고로만 표시한다.
- 요율 영향 미리보기는 기존 승인 계산 결과를 후보 요율로 재산출해 예상 증감과 0원화 경고를 보여준다.

## 남은 리스크
- 전체 `npm run test`는 제한 시간 안에 완료되지 않아 전체 회귀 통과로 판단하지 않았다.
- Electron navigation/CSP 제한과 인증 bootstrap 변경은 의도적으로 제외했으므로 별도 승인 후 분리 적용해야 한다.
- 수동 Excel 재출력 QA와 Electron UI QA는 아직 필요하다.
