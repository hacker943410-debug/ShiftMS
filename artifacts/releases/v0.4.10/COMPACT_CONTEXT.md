# v0.4.10 Compact Context

## 배경
- 사용자 PC에서 `C:\연장근무관리\승인대기\YYYY년\M월\YYYY_M_근무지명.xlsx` 구조로 실적 파일이 누적되어 있었다.
- 기존 실적 관리 조회는 승인대기 루트 하위 전체를 재귀 스캔하고 모든 Excel을 열어 앱이 응답 없음 상태처럼 보일 수 있었다.
- 복구키가 발급되지 않은 기존 설치본에서는 로그인 후 복구키를 발급할 수 없어 별도 유지보수 경로가 필요했다.

## 이번 변경
- 승인대기 실적 동기화를 선택 월 기준으로 제한한다.
- 변경 없는 파일은 기존 DB 분석 결과를 재사용한다.
- 파싱 진행률을 renderer 내부모달로 표시한다.
- 규격 불일치 Excel은 `syncIssues`로 전달해 파일명/경로/사유를 모달로 보여준다.
- `issue-account-recovery-key.cmd/.mjs`를 설치 리소스에 포함한다.
