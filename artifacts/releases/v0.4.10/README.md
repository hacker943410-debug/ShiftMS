# v0.4.10 릴리즈 작업 폴더

## 목적
- 승인대기 실적 조회 시 누적된 연도/월 폴더 전체를 파싱해 앱이 멈춘 것처럼 보이는 문제를 완화한다.
- 실적 Excel 파싱 진행률과 규격 불일치 원인을 내부모달로 안내한다.
- 로그인 불가 상황에서 복구키를 발급할 수 있는 유지보수 스크립트를 설치본에 포함한다.

## 핵심 산출물
- `RELEASE_MANIFEST.json`: 앱 내부 패치노트와 GitHub Release 기준
- `FUNCTIONAL_SPEC.md`: 기능 동작 기준
- `QA_CHECKLIST.md`: 검증 기준
- `RESULT_REPORT.md`: 구현 및 검증 결과
