# v0.4.10 기능 기준

## 승인대기 실적 조회
- 연도와 월 필터가 모두 선택된 경우 해당 `YYYY년/M월` 폴더를 우선 스캔한다.
- 파일명 `YYYY_M_근무지명.xlsx` 또는 경로 `YYYY년/M월`에서 월 정보를 해석한다.
- 같은 경로의 파일 크기와 수정 시간이 기존 저장값과 같으면 Excel을 다시 열지 않는다.
- Excel 임시파일 `~$*.xlsx`는 실적 파일 후보에서 제외한다.

## 파싱 진행률
- 실적 관리 화면이 overview를 불러오는 동안 내부모달로 진행률을 표시한다.
- 표시 항목은 현재 파일명, 파일 경로, 처리 개수, 진행률, 분석/재사용/확인필요 건수다.
- 파일 사이에 짧은 대기 시간을 두어 화면 갱신 기회를 확보한다.

## 규격 오류 안내
- 첫 번째 시트가 `교대 근무 계획표`가 아니거나 지원하지 않는 양식이면 error 상태로 저장한다.
- 사용자는 내부모달에서 파일명, 전체 경로, 오류 사유를 확인한다.

## 계정복구키 발급 스크립트
- 배치 파일은 Node.js가 있으면 Node.js로 실행한다.
- Node.js가 없으면 설치된 `ShiftMgmt.exe`를 Node 런타임처럼 사용한다.
- DB를 찾으면 백업 후 admin 계정복구키를 발급하고, 원문 키는 콘솔에 1회 표시한다.
