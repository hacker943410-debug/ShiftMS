# Functional Spec

## 운영 관리 > 패치이력
1. 패치이력 목록은 게시판 표 형태로 표시한다.
2. 게시글 제목은 `Patch Note 0.4.8`처럼 버전 번호를 포함한다.
3. 게시글을 클릭하면 해당 버전의 상세 패치노트 화면으로 이동한다.
4. 상세 화면에는 기존 `ReleaseManifestContent` 형식의 세부 내용을 표시한다.
5. `목록으로` 버튼을 통해 게시판 목록으로 돌아갈 수 있다.

## 업데이트 후 패치노트
1. 업데이트 후 실행 시 패치노트는 버전별로 한 화면씩 확인한다.
2. 중간 버전에서는 `이전`, `다음` 버튼을 제공한다.
3. 마지막 버전에서는 `다음` 대신 `마침` 버튼을 표시한다.

## 앱 실행 창
1. 프로그램 실행 시 메인 창은 최대화 상태로 표시한다.
2. 개발 실행과 패키징 실행 모두 동일하게 동작한다.

## 근무표 배포 Excel Calendar
1. 좌측 Calendar 날짜 셀은 템플릿 원본 서식과 관계없이 `DD일` 형식으로 표시한다.
2. Calendar 첫 주에 포함되는 이전달 날짜도 현재월 날짜와 동일한 표시형식을 사용한다.
3. 양식 미리보기와 실제 배포 파일은 동일한 Calendar 날짜 표시 기준을 사용한다.
