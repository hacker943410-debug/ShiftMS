# Compact Context

- 이번 패치 목표는 패치이력 화면을 펼쳐진 카드 목록에서 게시판형 목록과 상세 화면으로 바꾸는 것이다.
- 업데이트 후 패치노트 모달은 버전별 이동 흐름을 유지하되 마지막 단계의 완료 버튼을 `마침`으로 표시해야 한다.
- 프로그램 실행 시 창은 사용자가 바로 넓은 화면에서 작업할 수 있도록 최대화 상태로 표시한다.
- 근무표 배포 Excel 좌측 Calendar의 이전달 날짜도 현재월 날짜와 동일하게 `DD일` 형식으로 표시해야 한다.
- 기능 로직보다 운영자가 보는 UX 정리가 핵심이므로 기존 bridge, manifest, release history service 구조는 유지한다.
