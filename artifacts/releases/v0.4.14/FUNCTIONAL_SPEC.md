# v0.4.14 Functional Spec

## 인력관리 목록
- 필터는 `근무지 / 현재상태 / 고용형태 / 배정상태`를 좌측에 배치한다.
- 검색은 우측에 배치하고 `이름 / 연락처 / 사원번호`를 대상으로 한다.
- 페이지당 표시 건수는 `10 / 20 / 50`이며 기본값은 `10`이다.
- 필터, 검색어, 페이지 크기가 변경되면 현재 페이지는 1페이지로 초기화한다.
- 정렬은 `근무지명 -> 조이름 -> 사원번호` 오름차순이다.

## 직원 데이터
- 연락처는 선택 입력값이며 기존 데이터는 공백으로 유지한다.
- 고용형태는 `정규 / 계약 / BP`만 표시한다.
- `파견 / 용역` 계열 입력값은 `계약`으로 저장/표시한다.
- BP만 사원번호와 시급 미입력을 허용하고, 정규/계약은 기존 기준을 따른다.

## 삭제 근무지 배정 인력
- 삭제된 근무지에 현재 배정이 남아 있는 인력은 인력관리 목록과 집계에서 제외한다.
- DB 자동 수정, 배정 자동 해지, 이력 삭제는 하지 않는다.
- 제외 대상은 내부 모달로 확인한다.

## 별첨1/수당
- 별첨1 Excel 선택값 없는 숫자 칸은 Blank로 둔다.
- 별첨1 필수 컬럼 누락 검증은 유지한다.
- 별첨1 Excel 시급 셀은 숫자값과 `#,##0.00원` 표시 형식을 사용한다.
- 별첨1 PDF 시급은 `15,000.00원` 형식으로 표시한다.
- 수당은 `시급 * 요율 * 근로시간` 결과를 `Math.ceil`로 원 단위 올림 처리한다.
- 기본 별첨1 Excel 양식은 `별첨1_2026-04_수정본.xlsx`이며 최종 출력 파일에는 `별첨1` 시트만 남긴다.
- 퇴사자 조기 지급 대상이 없어도 조기 지급 블록과 `해당 없음` 행을 출력한다.
- 별첨1 하단 안내는 새 샘플 기준 정적 `Sort`와 계산식 안내를 사용한다.

## 품의서 양식
- 기본 품의서 Excel 양식은 `품의서_2026-04_수정본.xlsx`이다.
- 최상단 결재 구분은 `☑ 품의`, `☐ 보고` 체크박스 표기로 출력한다.
- `당월 지급 대상자` 수는 일반 지급 대상자와 퇴사자 조기 지급 대상자를 모두 포함한 고유 인원 수로 출력한다.
- 최상단 로고는 배경 제거 로고를 사용하고 `A1:C1` 범위에 맞춰 배치한다.
- 작성자/전화번호, `총 합계`, 총합계 금액은 검정색 폰트로 출력한다.
- 총합계 행 `B30:H30` 테두리는 두 번째 굵기인 `medium`으로 출력한다.
- 퇴사자 조기 지급 내역 표는 조기 지급 사이트 요약 수에 따라 행을 동적으로 삽입/삭제한다.
- 일반 지급, 퇴사자 조기 지급, 총 합계, 지급 요청일/세부내역 구조를 출력한다.
- 근무지 수에 따라 각 표와 footer 행 위치는 동적으로 이동한다.
