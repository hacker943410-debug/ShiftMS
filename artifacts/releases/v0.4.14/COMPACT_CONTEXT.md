# v0.4.14 Compact Context

0.4.14는 인력관리 화면의 조회 UX와 직원 데이터 기준을 정리하는 패치다. 직원 연락처를 SQLite `employees.contact`에 추가하고, 인력관리 신규 등록/프로필 저장/검색에 반영한다. 고용형태는 `정규 / 계약 / BP`만 사용하며 파견/용역은 계약으로 정규화한다.

삭제된 근무지에 활성 배정이 남아 있는 인력은 DB를 자동 변경하지 않고 인력관리 목록과 집계에서 제외한다. 제외 대상은 배너와 내부 모달에서 `사원번호 / 이름 / 삭제된 근무지 / 조이름`으로 확인한다.

별첨1 Excel은 0 또는 없음인 선택 수당/시간/요율 칸을 Blank로 출력한다. 시급 셀은 숫자값을 유지하고 `#,##0.00원` 표시 형식을 적용한다. PDF 시급 표기는 소수점 둘째 자리까지 표시한다. 수당 계산은 `roundUpWon` 기준 원 단위 올림을 사용한다.
