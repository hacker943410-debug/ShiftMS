# v0.4.14 Compact Context

0.4.14는 인력관리 화면의 조회 UX와 직원 데이터 기준을 정리하는 패치다. 직원 연락처를 SQLite `employees.contact`에 추가하고, 인력관리 신규 등록/프로필 저장/검색에 반영한다. 직원 직급은 `사원 / 대리 / 과장 / 차장 / 부장` 선택값으로 관리하며 SQLite `employees.rank`, `performance_entries.employee_rank`, `allowance_calculations.employee_rank`에 저장한다. 기존 `department` 호환 값은 저장/표시 호환을 위해 유지하고, 새 직급 필드는 별도 컬럼으로 분리한다. 고용형태는 `정규 / 계약 / BP`만 사용하며 파견/용역은 계약으로 정규화한다.

Access DB 직접 확인 결과 `사업조직별근무자현황`에는 직급 컬럼이 없고 `사업조직별근무실적`에 `직급명` 컬럼이 있다. 복원은 별칭 추정 없이 `사업조직별근무실적.직급명`만 직급 선택값으로 정규화해 이관한다. 인력 기본정보 직급은 사원번호별 최신 `근무날짜` 실적의 직급으로 보강한다. 실적 승인과 수당 산출 결과에는 승인/산출 시점의 직급 스냅샷을 보존하고, 별첨1 Excel 상세 표 D열은 이 직급을 출력한다. 직급이 없는 기존 데이터는 별첨1에서 `-`로 표시한다.

삭제된 근무지에 활성 배정이 남아 있는 인력은 DB를 자동 변경하지 않고 인력관리 목록과 집계에서 제외한다. 제외 대상은 배너와 내부 모달에서 `사원번호 / 이름 / 삭제된 근무지 / 조이름`으로 확인한다. 인력관리 테이블의 `프로필 보기` 버튼은 텍스트와 보기 아이콘만 표시하고 이름 앞글자 아이콘은 사용하지 않는다.

별첨1 Excel은 0 또는 없음인 선택 수당/시간/요율 칸을 Blank로 출력한다. 시급 셀은 숫자값을 유지하고 `#,##0.00원` 표시 형식을 적용한다. PDF 시급 표기는 소수점 둘째 자리까지 표시한다. 수당 계산은 `roundUpWon` 기준 원 단위 올림을 사용한다.

기본 품의서/별첨1 양식은 2026-04 수정본으로 갱신한다. 품의서는 최상단 `품의/보고` 체크박스 표기를 출력하고, `당월 지급 대상자` 수에 퇴사자 조기 지급 대상자를 포함하며, 배경 제거 로고를 `A1:C1`에 배치한다. 작성자/전화번호/총합계 폰트색은 검정색으로 맞추고 총합계 `B30:H30` 테두리는 두 번째 굵기인 `medium`을 사용한다. 퇴사자 조기 지급 표는 조기 지급 사이트 요약 수에 따라 동적으로 늘어난다. 품의서는 일반 지급, 퇴사자 조기 지급, 총 합계, 지급 요청일/세부내역 구조를 유지한다. 별첨1은 최종 출력에서 `별첨1` 시트만 남기고, 상세 표 D열에 직급을 출력하며, 퇴사자 조기 지급 대상이 없어도 `해당 없음` 행과 새 샘플 기준 정적 계산 안내를 출력한다. 조기 지급 `해당 없음` 행의 숫자 영역 `H:S`는 Blank로 둔다. 하단 계산식 영역은 샘플 `별첨1` 시트 `24:45`행의 문구/서식/병합/행높이를 그대로 복제한다.
