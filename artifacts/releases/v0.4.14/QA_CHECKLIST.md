# v0.4.14 QA Checklist

- [ ] 인력관리 상단 필터가 한 줄로 보이고 검색 입력이 우측에 표시된다.
- [ ] 이름, 연락처, 사원번호 검색이 각각 동작한다.
- [ ] 페이지당 10/20/50명 변경 시 1페이지로 초기화된다.
- [ ] 인력관리 목록 정렬이 근무지명, 조이름, 사원번호 순으로 적용된다.
- [ ] 신규 인력 등록과 프로필 저장에서 연락처가 저장/수정된다.
- [ ] 고용형태 옵션이 정규/계약/BP만 표시된다.
- [ ] 파견/용역 데이터가 계약으로 정규화된다.
- [ ] 삭제된 근무지 배정 인력이 목록/집계에서 제외되고 대상 보기 모달에 표시된다.
- [ ] 별첨1 Excel 선택값 없는 시간/요율/수당 칸이 Blank로 출력된다.
- [ ] 별첨1 Excel 시급 셀이 숫자값이며 `#,##0.00원` 형식으로 표시된다.
- [ ] 별첨1 PDF 시급이 소수점 둘째 자리까지 표시된다.
- [ ] 소수점 수당 계산 결과가 원 단위 올림으로 저장된다.
- [ ] 기본 품의서 양식이 `품의서_2026-04_수정본.xlsx` 기준 일반 지급/퇴사자 조기 지급/총 합계 구조로 출력된다.
- [ ] 품의서 Excel 최상단에 `☑ 품의`, `☐ 보고` 체크박스 표기가 출력된다.
- [ ] 품의서 Excel의 `당월 지급 대상자` 수가 퇴사자 조기 지급 대상자를 포함한다.
- [ ] 품의서 Excel 최상단 로고가 배경 제거 로고로 `A1:C1` 범위에 맞춰 출력된다.
- [ ] 품의서 Excel 작성자/전화번호, `총 합계`, 총합계 금액 폰트색이 검정색으로 출력된다.
- [ ] 품의서 Excel 총합계 행 `B30:H30` 테두리 두께가 `medium`으로 출력된다.
- [ ] 품의서 Excel 퇴사자 조기 지급 내역 표가 조기 지급 사이트 요약 수에 따라 동적으로 늘어난다.
- [ ] 기본 별첨1 양식이 `별첨1_2026-04_수정본.xlsx` 기준으로 출력되며 최종 파일에는 `별첨1` 시트만 남는다.
- [ ] 퇴사자 조기 지급 대상이 없어도 별첨1의 조기 지급 블록에 `해당 없음` 행이 출력된다.
- [ ] 별첨1 하단 안내가 새 샘플 기준 `Sort`와 정적 계산식 안내로 출력된다.
