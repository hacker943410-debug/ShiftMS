# v0.4.14 QA Checklist

- [ ] 인력관리 상단 필터가 한 줄로 보이고 검색 입력이 우측에 표시된다.
- [ ] 이름, 연락처, 사원번호 검색이 각각 동작한다.
- [ ] 페이지당 10/20/50명 변경 시 1페이지로 초기화된다.
- [ ] 인력관리 목록 정렬이 근무지명, 조이름, 사원번호 순으로 적용된다.
- [ ] 신규 인력 등록과 프로필 저장에서 연락처가 저장/수정된다.
- [ ] 고용형태 옵션이 정규/계약/BP만 표시된다.
- [ ] 파견/용역 데이터가 계약으로 정규화된다.
- [ ] 삭제된 근무지 배정 인력이 목록/집계에서 제외되고 대상 보기 모달에 표시된다.
- [ ] 별첨1 Excel 선택값 없는 시간/요율/수당 칸이 Blank로 출력된다.
- [ ] 별첨1 Excel 시급 셀이 숫자값이며 `#,##0.00원` 형식으로 표시된다.
- [ ] 별첨1 PDF 시급이 소수점 둘째 자리까지 표시된다.
- [ ] 소수점 수당 계산 결과가 원 단위 올림으로 저장된다.
