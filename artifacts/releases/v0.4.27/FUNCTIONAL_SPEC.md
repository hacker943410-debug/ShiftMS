# Functional Spec

## 실적관리 조별 검수
- 근무지 요약 행을 펼치면 조별 요약 행을 먼저 표시한다.
- 조별 요약에는 실적, 승인, 대기, 반려, 재검토, 알림 건수를 표시한다.
- 조 정보가 없는 행은 `미지정 조`로 묶는다.

## 반려 파일 재파싱
- 승인대기 폴더의 파일이 DB에서 `rejected` 상태이면 조회 시 재파싱한다.
- 재파싱 후에도 반려 상태는 유지해 재승인 흐름을 이어간다.
- 같은 파일의 기존 실적 엔트리는 삭제 후 현재 Excel 기준으로 다시 저장한다.

## None 취소
- 원근무자 셀이 `None`이면 해당 슬롯은 실적 대상에서 제외한다.
- 같은 슬롯의 변경 후 셀이 `None`이면 해당 슬롯은 실적 대상에서 제외한다.
- 변경/대체 표에서 `원근무자 -> None`이면 같은 날짜의 원근무자 법정휴일 실적은 생성하지 않는다.

## 로그인 실패
- 비밀번호 실패 횟수는 기록하지만 계정 잠금 만료 시각은 설정하지 않는다.
- 로그인 화면에는 5회 실패 잠금 안내를 표시하지 않는다.
