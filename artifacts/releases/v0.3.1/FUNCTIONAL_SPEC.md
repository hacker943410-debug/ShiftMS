# v0.3.1 기능 명세 요약

## 사용자 관점 동작
- 재승인 확정과 승인완료 보관본 조회는 현재 파일 기준으로 더 엄격하게 동작한다.
- 요율 수정은 오늘 이전 적용 시작일 변경을 제한하고, 수정 시에만 변경 사유와 이력을 남긴다.
- 품의서/별첨1/별첨2는 최신 로고와 제목 규칙, 병합/배경색/소계/합계 기준으로 출력한다.

## 검증 포인트
- 화면 동작과 저장 결과가 동일한 업무 의미를 유지해야 한다.
- 관련 이력과 출력/백업 산출물이 조용히 덮어써지지 않아야 한다.
- 운영자가 가이드/문서만으로 후속 조치를 판단할 수 있어야 한다.
