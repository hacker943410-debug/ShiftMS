# v0.3.1 Compact Context

## 한 줄 목표
- 0.3.0에서 재구성한 업무 흐름을 감사성과 운영 안정성 기준으로 마감하고, 가이드/양식/UI를 정리한다.

## 현재 범위
- 실적 재승인, 근무지 반려, 품의 승인 트랜잭션, DB 백업을 하드닝한다.
- 가이드 모달 구조, 하이라이트, 설명 데이터, dashboard/login UI를 정리한다.
- 품의서/별첨1/별첨2 PDF/Excel 양식, 로고, 배경색, 병합/테두리 잔재를 정리한다.

## 구현/운영 원칙
- renderer는 UI와 안내만 담당하고, 파일/DB/문서 처리는 main/preload를 통해서만 수행한다.
- 계산, 승인, 이력, 출력 규칙은 shared 또는 main service에 둔다.
- 조용한 덮어쓰기보다 이력 기반 재현성과 운영자 확인을 우선한다.
