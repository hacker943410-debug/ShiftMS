# v0.3.1 작업 폴더

## 목적
- 이 폴더는 v0.3.1 패치/릴리즈의 분석, 구현, QA, 결과 문서를 한 위치에서 관리한다.

## 현재 상태
- 기준일: 2026-04-09
- 성격: 업무 흐름 하드닝, 가이드 재구성, 출력 양식 정리
- 상태: 패치 구현/자동 검증 완료, 수동 QA 대기

## 문서 구성
- COMPACT_CONTEXT.md: 이번 버전의 목표와 범위를 압축 정리한다.
- IMPLEMENTATION_ANALYSIS.md: 구현 배경, 제약, 설계 방향을 요약한다.
- FILE_IMPACT.md: 핵심 변경 영역을 경로 단위로 정리한다.
- FUNCTIONAL_SPEC.md: 사용자 관점 동작과 검증 포인트를 정리한다.
- TODO.md: 구현/검증 단계를 체크리스트로 남긴다.
- QA_CHECKLIST.md: 자동 검증과 수동 확인 기준을 기록한다.
- RESULT_REPORT.md: 최종 결과와 남은 이슈를 정리한다.

## 이번 버전 요약
- 실적-수당-품의 흐름의 감사성과 운영 안정성을 마감 수준으로 끌어올렸다.
- 가이드 모달과 하이라이트 체계를 전면 정리해 사용자 안내 품질을 높였다.
- 품의서/별첨 양식의 로고, 제목, 병합, 테두리, 배경색, 소계/합계 규칙을 정리했다.
