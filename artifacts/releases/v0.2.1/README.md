# v0.2.1 작업 폴더

## 목적
- 이 폴더는 v0.2.1 패치/릴리즈의 분석, 구현, QA, 결과 문서를 한 위치에서 관리한다.

## 현재 상태
- 기준일: 2026-03-31
- 성격: 운영 UI와 DatePicker 사용성 보강
- 상태: 패치 구현 및 자동 검증 완료

## 문서 구성
- COMPACT_CONTEXT.md: 이번 버전의 목표와 범위를 압축 정리한다.
- IMPLEMENTATION_ANALYSIS.md: 구현 배경, 제약, 설계 방향을 요약한다.
- FILE_IMPACT.md: 핵심 변경 영역을 경로 단위로 정리한다.
- FUNCTIONAL_SPEC.md: 사용자 관점 동작과 검증 포인트를 정리한다.
- TODO.md: 구현/검증 단계를 체크리스트로 남긴다.
- QA_CHECKLIST.md: 자동 검증과 수동 확인 기준을 기록한다.
- RESULT_REPORT.md: 최종 결과와 남은 이슈를 정리한다.

## 이번 버전 요약
- 요율 적용 흐름과 DatePicker 공통 동작이 운영 화면 기준으로 안정화됐다.
- 수당 관리 화면 확장과 로고/별첨2 PDF 로고 보강을 함께 마쳤다.
- 패키지 버전은 0.2.1로 정리됐고, 상세 릴리즈 결과는 RESULT_REPORT에 요약했다.
