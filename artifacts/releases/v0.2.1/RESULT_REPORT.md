## 2. 구현 결과 요약
- 요율 적용:
  - `적용 중인 요율`을 좌측에 고정 표시하고, 조회 연도 기준 목록 선택과 우측 상세 확인 흐름을 추가했다.
  - 실제 승인 수당 계산은 이제 `적용 중인 요율`을 우선 기준으로 사용한다.
- 수당 관리 화면 확장:
  - `사업장별 수당 분포`, `상세 수당 내역` 각각에 펼치기 모드를 추가했다.
  - 좌측 펼치기에서는 차트 중심 7:3 비율, 우측 펼치기에서는 상세 테이블 전체 폭 보기로 전환된다.
- 문서 출력 / 앱 UI 보정:
  - 앱 좌측 상단 로고 배경을 주변 바탕색과 맞췄다.
  - 별첨2 PDF 우측 상단에 회사 로고를 추가했다.
- DatePicker 공통 보정:
  - `확인` 클릭 시 값 반영 후 닫힘
  - `취소` 클릭 시 원래 값 복원 후 닫힘
  - footer 버튼 이벤트를 보정해 label 래퍼 안에서도 재오픈 없이 안정적으로 닫히도록 수정했다.

## 5. 구현 판단 기준
- DatePicker는 공통 `DateField` 기준으로만 유지한다.
- `확인`과 `취소` 모두 팝오버를 닫아야 하며, 닫힘 이후 focus 이동으로 재오픈되면 안 된다.
- 개별 화면별 예외 처리는 피하고 공통 컴포넌트에서 동작을 통일한다.

## 6. 남은 이슈 / 비고
- 저장소 내 운영 샘플 Excel 템플릿 리뉴얼은 별도 후속 패치에서 진행한다.
- 이번 범위에는 양식 템플릿 구조 변경이나 추가 파싱 규칙 수정은 포함하지 않았다.
