# v0.2.1 Compact Context

## 한 줄 목표
- 운영 관리 요율 적용과 공통 DatePicker 동작을 안정화하고 화면 사용성을 보강한다.

## 현재 범위
- 운영 관리 요율 적용 흐름과 적용 중인 요율 표시를 추가한다.
- 수당 관리 좌우 패널 펼치기와 앱 로고 배경 정리를 진행한다.
- 공통 DatePicker 확인/취소/닫힘 동작을 적용 위치 전반에서 통일한다.

## 구현/운영 원칙
- renderer는 UI와 안내만 담당하고, 파일/DB/문서 처리는 main/preload를 통해서만 수행한다.
- 계산, 승인, 이력, 출력 규칙은 shared 또는 main service에 둔다.
- 조용한 덮어쓰기보다 이력 기반 재현성과 운영자 확인을 우선한다.
