# v0.4.1 Compact Context

## 한 줄 목표
- `0.4.0` 누적 변경을 유지한 채 인증/비밀번호 정책과 패키징 기준을 정리해 `0.4.1` 설치본으로 승격한다.

## 현재 범위
- 관리자 bootstrap 비밀번호와 추가 계정 bootstrap 흐름을 현재 운영 기준으로 정리한다.
- 첫 로그인/내 정보/운영 관리 사용자 비밀번호 입력을 같은 정책과 안내 문구로 맞춘다.
- Electron smoke 인증 helper를 공통화하고 installer / packaged / role 검증을 `0.4.1` 설치본 기준으로 다시 확인한다.
- 활성 릴리즈 문서와 버전 아카이브를 `v0.4.1` 기준으로 정리한다.

## 비목표
- `0.4.0`에서 이미 구현된 양식 관리, 복구, 권한 구조를 다시 설계하지 않는다.
- 수동 운영 QA와 릴리즈 PC 최종 승인 자체를 자동화로 대체하지 않는다.
- 새로운 네이티브 모듈이나 의존성을 추가하지 않는다.

## 확정 결정
- 현재 코드/설치본 버전은 `0.4.1` 를 기준으로 맞춘다.
- 관리자 bootstrap 기본 비밀번호는 `1234`, 추가 계정 bootstrap 비밀번호는 파일 기반으로 유지한다.
- 공통 비밀번호 정책은 shared 설정과 공통 폼에서 관리한다.
- 릴리즈 문서와 sign-off 로그는 `artifacts/releases/v0.4.1/` 기준으로 정리한다.

## 우선순위
1. 인증 / 비밀번호 정책 정리
2. `0.4.1` 패키징과 installer sign-off
3. 릴리즈 문서 / 아카이브 갱신
4. 운영 데이터 기준 수동 QA 준비
