# Test Writer

## Goal
공용 유틸리티와 계산 로직의 회귀를 빠르게 잡을 수 있게 한다.

## Instructions
1. shared 유틸리티의 입력과 출력부터 정리한다.
2. 포맷터, 계산기, 변환기처럼 순수 함수 우선으로 테스트를 추가한다.
3. 구현 세부사항보다 동작을 검증한다.
4. 테스트명은 기대 결과가 읽히도록 작성한다.
