# 화면설계 재정의

## 기준 원칙
- 이 문서는 2026-03-11 기준 최신 화면 기준서다.
- 우선 기준은 각 메뉴별 샘플 이미지다.
- 기능과 데이터 항목은 `../shftMgmgt설계_V3.4.md`를 따른다.
- 기존 배치가 샘플 이미지와 충돌할 경우 샘플 이미지 배치를 우선한다.
- 단, 설계 원문에 명시된 입력 항목이나 계산 정보가 샘플에 빠져 있으면 배치를 크게 깨지 않는 범위에서 보강한다.

## 공통 레이아웃

### 1. 앱 프레임
- 좌측 고정 사이드바 + 우측 메인 콘텐츠 구조
- 우측 상단에는 사용자 정보, 알림, 필요 시 검색창 배치
- 전체 톤은 라이트 모드 운영 콘솔
- 카드형 콘텐츠, 얇은 경계선, 낮은 그림자, 선명한 파란색 액션 버튼 사용

### 2. 공통 스타일
- 배경: 매우 연한 회색 계열
- 카드: 흰색 배경, 중간 라운드
- 주 액션 버튼: 진한 블루
- 보조 버튼: 흰색 또는 연한 회색 배경
- 테이블 헤더: 연회색 또는 블루 그레이 계열 배경
- 상태값: 텍스트 + 배지 조합

### 3. 구현 원칙
- 샘플 이미지의 시각 배치를 최대한 그대로 유지한다.
- 실제 구현 시 데이터가 많아지는 영역은 스크롤과 페이징을 허용한다.
- 설계 원문에 있는 필드와 계산 항목은 UI에서 빠지면 안 된다.

## 요청 1. 대시보드

### 기준 이미지
- `대시보드.jpg`

### 최종 배치
- 상단: 페이지 제목 `Dashboard`
- 상단 우측: 알림, 사용자 프로필 카드
- 필터 행: 연도, 월, 근무지, 이름, 우측 `조회` 버튼
- 1행 KPI 카드 4개
  - 대체근로시간
  - 연장근로시간
  - 야간근로시간
  - 총근로시간
- 2행 KPI 카드 4개
  - 대체근로수당
  - 연장근로수당
  - 야간근로수당
  - 총근로수당
- 3행 차트 2개
  - 월별 근무유형 트렌드
  - 근무 유형 분포
- 4행 차트 2개
  - 연장근로 시간 변동 추이
  - 수당 항목별 비중 분석

### 반영 규칙
- 현재 임시로 사용한 막대형 요약 카드는 `대시보드.jpg`의 카드형 아이콘 KPI 배치로 변경
- 차트는 더미여도 샘플과 같은 2x2 배치 구조 유지
- 좌측 메뉴 톤은 현재 콘솔 구조 유지 가능하나, 본문 카드 밀도는 샘플과 동일 수준으로 맞춘다

## 요청 2. 인력관리

### 기준 이미지
- `인력관리.jpg`

### 최종 배치
- 좌측 사이드 메뉴 유지
- 우측 상단: `신규 인력 등록` 버튼
- 본문 상단 제목: `근무 인력 관리`
- 제목 하단 설명: 사원 명부 및 교대근무 현황
- 필터 행 1줄
  - 근무지
  - 현재상태
  - 처리결과
  - 이름/사원번호 검색
- 메인 콘텐츠: 단일 대형 테이블 카드

### 테이블 컬럼
- No.
- 사원번호
- 직급
- 이름
- 근무지
- 조이름
- 통상시급
- 역할
- 근무기간
- 프로필

### 프로필 컬럼 동작
- 우측 프로필 영역에 이니셜 아바타 + 이름 + 수정 아이콘 + 상세 아이콘 배치
- 상세 아이콘 클릭 시 인력상세페이지 이동

### 반영 규칙
- 현재처럼 목록과 상세를 한 화면에 같이 배치하지 않는다
- 목록 화면은 샘플처럼 테이블 중심 단일 화면으로 재배치
- 상세는 별도 화면으로 분리

## 요청 3. 근무지 등록 1단계

### 기준 이미지
- `근무지관리1단계.png`

### 최종 배치
- 상단 좌측: 단계 표시
  - 1단계 패턴 등록 활성
  - 2단계 조직 구성 비활성
- 본문 상단 제목: `근무지 등록 - 1단계: 패턴 등록`
- 좌측 카드: 기본 정보 및 패턴 설정
- 우측 대형 카드: 근무 패턴 시뮬레이션 결과
- 하단 좌측: `뒤로가기`
- 하단 우측: `적용`, `다음 단계`

### 좌측 입력 카드 항목
- 근무지명
- 패턴 String
- 근무유형
- 근무 정원
- Pool 근무 여부
- 근무시간
- 휴게시간
- 패턴 시작일
- 조별 Index 입력란 추가
  - 근무유형에 따라 A조, B조, C조, D조 ... 동적 생성
  - 예: 4조 3교대면 A~D
  - 예: 6조 3교대면 A~F

### 우측 시뮬레이션 카드
- 월간 달력
- 조별 근무유형 범례
- 하단 요약 카드 또는 요약 영역
  - 총근로시간(주간)
  - 총근로시간(월간)
  - 총 법정휴일근로시간(주간)
  - 총 법정휴일근로시간(월간)
  - 필요 시 기본근로시간, 연장근로시간, 야간근로시간 추가

### 반영 규칙
- 샘플의 좌측 입력 / 우측 결과 2단 구조는 유지
- 설계 원문에 있던 통계 정보는 우측 하단 KPI로 보강
- 조별 Index 입력은 샘플에 없더라도 반드시 추가

## 요청 4. 근무지 등록 2단계

### 기준 이미지
- `근무지등록 2단계.png`

### 최종 배치
- 상단 단계 표시
  - 1단계 근무유형 설정
  - 2단계 조직 구성 활성
- 본문 제목: `조직 구성`
- 좌측 카드: 미배정 인원 리스트
- 우측 대형 카드: 선택한 조 배정 영역
- 우측 상단 탭: A조, B조, C조, D조 ...
- 하단 요약 카드: 각 조 배정 현황
- 하단 버튼: `이전 단계`, `임시 저장`, `완료`

### 좌측 카드 보강
- 검색창 유지
- 필터 추가
  - 미배정 인원
  - 타 근무지 근무중 인원
  - 전체
  - 근무지별 필터
- 카드 리스트는 드래그 소스 역할

### 우측 배정 영역 보강
- 현재 선택 조에 대한 Drop Zone 표시
- 이미 다른 근무지에 속한 인원은 배정 전 경고 상태 표기
- 조의 개수는 1단계의 근무유형 기준으로 동적 활성화

### 반영 규칙
- 샘플의 좌측 리스트 / 우측 드롭존 / 하단 조별 요약 구조 유지
- 설계 원문 요구에 따라 다른 근무지 소속 인원 조회 필터를 추가

## 요청 5. 인력상세페이지

### 기준 이미지
- `인력상세페이지.png`

### 최종 배치
- 좌측에는 이전 목록 화면이 흐리게 보이는 오버레이 스타일을 참고하되, 실제 구현은 전체 독립 화면 또는 슬라이드 패널로 처리 가능
- 중앙 좌측 정보 카드
  - 사원번호
  - 이름
  - 입사일
  - 직무적용일
  - 근무지
  - 근무조명
  - 상태
- 중앙 입력 카드
  - 직무해제일/예정일
  - 통상시급
- 우측 2개 이력 영역
  - 근무변경이력
  - 시급변경이력
- 각 이력 영역은 10건 이상 스크롤 제공

### 반영 규칙
- 수정 불가 정보는 왼쪽 세로 정보 카드에 고정
- 수정 가능 정보는 가운데 입력 영역에 배치
- 오른쪽 이력 패널은 세로 스크롤형 타임라인 구조로 구현
- 입력은 숫자만 받되 표시 형식은 `#,##0원`

- 색상/테마 기준: `근무표배포설정.png`

### 최종 배치
- 상단 필터 영역
  - 연도
  - 월
  - 근무지
- 중앙 좌측 대형 달력
  - 일~토 주간 달력
  - 각 날짜 칸 내 근무조별 인력명 표시
- 우측 요약 패널 2개
  - 주간 근로시간 테이블
  - 월간 근로시간 테이블
- 하단 경로 영역
  - 배포경로 설정
  - 경로 입력창
  - 경로 선택 버튼

### 반영 규칙
- 현재 카드형 웹 대시보드 스타일보다, 더 표 중심의 데스크톱 업무 화면에 가깝게 조정
- 주간/월간 통계는 우측 고정 패널 구조로 배치

## 요청 8. 수당관리

### 기준 이미지
- `수당관리.png`

### 최종 배치
- 상단 좌측 뒤로가기 아이콘
- 상단 제목: `수당 관리`
- 상단 우측 액션
  - 품의 신청
  - 엑셀 내보내기
- 필터 카드 1줄
  - 연도
  - 월
  - 사업장
  - 우측 초기화
- 본문 2열 구성
  - 좌측: 사업장별 수당 분포 카드 + 수당 유형별 비중 카드
  - 우측: 상세 수당 내역 테이블
- 상세 테이블 상단 검색창
- 상세 행 확장 시 계산 근거와 근무시간 정보 표시
- 하단 페이징 유지

### 반영 규칙
- 현재 단순 바차트 + 테이블 조합이 아니라 샘플의 좌측 분석 카드 2개 + 우측 확장형 테이블 구조로 바꾼다
- 확장 행에는 기본/연장/야간 수당 계산 근거를 표시한다
