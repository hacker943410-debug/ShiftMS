제공해주신 상세한 개발 요청 문서를 바탕으로, Electron 기반 로컬 데스크톱 애플리케이션의 UI/UX 디자인 시안을 구성했습니다.

전반적인 디자인 콘셉트는 대량의 데이터를 다루는 본사 관리자를 위해 **깔끔함, 가독성, 직관적인 데이터 식별**에 초점을 맞췄습니다.

# [디자인 시안] SM사업팀 교대근무 관리 시스템

## 0. 공통 레이아웃 구성

애플리케이션은 좌측 고정 메뉴바와 우측 메인 콘텐츠 영역으로 나뉩니다. 전체 콘셉트는 `디자인지시서.md`를 기준으로 한 **전문적인 라이트 모드 운영 콘솔**이며, 세부 구현 규칙은 `docs/ui-style-guide.md`를 따릅니다.

- 좌측 상단 브랜드 영역은 `Logo.png`를 기본 로고 자산으로 사용합니다.
- 메인 UI는 아주 연한 배경, 화이트 카드, 로얄 블루 액센트 조합으로 구성합니다.
- 테이블, 카드, 차트는 Ant Design 계열처럼 간격과 정렬 규칙을 일정하게 유지합니다.
- 카드와 버튼은 기본적으로 8px 라운딩을 사용합니다.
- 기본 서체는 Pretendard, KPI 숫자와 라틴 텍스트는 Inter 계열을 우선 사용합니다.

### 0.2. 아이콘 및 상태 표현 규칙

1. 문서 안의 `[아이콘: ...]` 표기는 실제 구현 시 SVG 아이콘으로 치환합니다.
2. 이모지는 사용하지 않고 Lucide 또는 Heroicons 계열처럼 선형 아이콘을 사용합니다.
3. 상태 정보는 색상만 쓰지 않고 `배지 텍스트 + 색상` 조합으로 표시합니다.
4. 차트는 장식용이 아니라 비교와 추이를 판단하는 용도로만 사용합니다.

## 3. 메뉴 3: 근무지 관리

가장 복잡한 설정 영역으로, 1단계(패턴/시뮬레이션)와 2단계(인원 배정)로 명확히 구분하여 UI를 구성합니다.

**디자인 시안:**

```text

+----------------------------------+ +----------------------------------+
| [기본 설정]                      | | [조별 패턴 시작 index]           |
| 근무지명: [ 입력... ]            | | (근무유형 선택 시 동적 생성)     |
| 패턴String: [주주야야휴휴]       | | A조: [ 0 ]   B조: [ 2 ]          |

[적용] -> (활성화됨) [다음 단계 (조직 구성) ▶]
```
