# 근무표 배포 양식 사양

## 목적

근무표 배포는 `근무표_템플릿1.xlsx`, `근무표_템플릿2.xlsx` 두 가지 운영 양식을 지원한다.
두 템플릿 모두 샘플 파일을 기준으로 만들되, 샘플 데이터가 남지 않는 빈 운영 템플릿을 사용한다.

## 공통 원칙

1. 배포 화면에서 등록된 `schedule` 템플릿 버전을 선택한다.
2. 선택한 템플릿 버전 ID를 월간 근무표와 함께 저장한다.
3. preview/export는 저장된 템플릿 버전을 우선 사용한다.
4. 사이트명, 기준월, 팀 요약, 날짜, 정규 계획만 시스템이 채운다.
5. 변경 계획, 변경 사유, 대체근무 이력, 연장근무 로그는 빈 상태로 배포한다.
6. 실명 기반 드롭다운은 템플릿 생성 시 제거하고, 일반 사유/시간 드롭다운만 유지한다.

## 양식 1

- 기반 샘플: `근무표_샘플1.xlsx`
- 운영 파일: `근무표_템플릿1.xlsx`
- 용도: `4조 2교대`, `3교대 포함 일반형`
- 좌측 메인 표:
  - 6주 x 7일
  - 주차 시작 행: `9, 15, 21, 27, 33, 39`
  - 표시 구조: `Day / Evening / Night / DAY OFF`
  - 팀 코드는 각 날짜 블록의 가운데 열에 쓴다.
  - `DAY OFF`는 세로 2칸까지 채운다.
- 중앙 변경관리 표:
  - 날짜 `Y12:Y42`
  - 정규 계획: `Z:AK`
  - 변경 계획: `AL:AW`
  - 변경 사유: `AX:AY`
- 월 앵커: `AY8`, `BK8`, `BK30`

## 양식 2

- 기반 샘플: `근무표_샘플2.xlsx`
- 운영 파일: `근무표_템플릿2.xlsx`
- 용도: `6조 2교대형`
- 좌측 메인 표:
  - 6주 x 7일
  - 주차 시작 행: `9, 19, 29, 39, 49, 59`
  - 표시 구조: `Day / Night / DAY OFF`
  - `Day Shift`는 하루당 3칸까지 채운다.
  - `Night Shift`는 가운데 열 1칸을 쓴다.
  - `DAY OFF`는 세로 5칸까지 채운다.
- 중앙 변경관리 표:
  - 날짜 `Y12:Y42`
  - 정규 계획: `Z:AO`
  - 변경 계획: `AP:BE`
  - 변경 사유: `BF:BG`
- 월 앵커: `BG8`, `BS8`, `BS30`
- 제약:
  - `E` 근무가 있는 3교대 패턴에는 사용할 수 없다.

## 팀 코드 규칙

1. 저장된 `teamLabel`을 기준으로 정렬 후 `A`, `B`, `C` 순으로 코드화한다.
2. 정렬은 한국어/숫자 자연 정렬을 사용한다.
3. 좌측 메인 표는 팀 코드 중심으로 채운다.
4. 중앙 정규 계획 표는 실제 직원명으로 채운다.
5. 각 날짜의 `DAY OFF` 코드는 활성 근무조를 제외한 나머지 팀 코드로 계산한다.

## 상단 요약 규칙

1. 양식 1은 `A: 이름1, 이름2` 형식의 기본 팀 요약을 사용한다.
2. 양식 2는 `기본 그룹 현황`, `주말 그룹 현황` 2줄 형식을 사용한다.
3. 현재 데이터 모델에 별도 주말 그룹 정의가 없으면 양식 2의 주말 그룹 줄은 기본 팀 기준으로 표시한다.

## 구현 메모

1. 샘플 파일은 참고본으로 유지한다.
2. 실제 export는 템플릿 파일을 사용한다.
3. 템플릿 선택 UI는 근무표 배포 화면의 필터 영역에 둔다.
4. 저장 후 export는 선택된 템플릿 레이아웃에 맞춰 셀 배치를 다르게 처리한다.
