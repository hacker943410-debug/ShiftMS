# 사용자 설명서

## 목적
교대근무관리시스템은 인력 기준정보, 근무지 패턴, 근무표 배포, 실적 승인, 수당 산출, 품의 승인, 문서 출력, 운영 기준정보를 하나의 로컬 데스크톱 앱에서 관리한다.

## 기본 사용 순서
1. `운영 관리 -> 경로 설정`에서 승인 대기 폴더, 승인 완료 폴더, 근무표 출력 폴더, 품의서/별첨 출력 폴더, DB 백업 경로를 저장한다.
2. `운영 관리`에서 공휴일, 요율, 사용자, 사이트 명, 양식 기준을 확인한다.
3. `인력 관리`와 `근무지 관리`에서 운영 기준정보를 정리한다.
4. `근무표 배포`에서 대상 월과 근무지의 월간 근무표를 출력한다.
5. 회수된 실적 파일을 승인 대기 폴더에 넣고 `실적 관리`에서 승인한다.
6. `수당 관리`에서 산출 결과를 검토하고 승인한다.
7. 최종 마감 시 `수당 관리 -> 품의 승인`으로 품의서/별첨 문서 출력과 품의 승인 기록을 남긴다.
8. `대시보드`와 `활동 이력`에서 운영 결과와 처리 이력을 확인한다.

## 공통 화면
- 좌측 메뉴에서 업무 화면을 이동한다.
- 우측 상단 가이드 버튼으로 현재 메뉴의 사용 순서를 확인한다.
- 관리자 전용 메뉴는 관리자 계정에서만 보인다.
- 확인, 사유 입력, 반려 사유 입력은 앱 내부 모달에서 처리한다.

## 대시보드
주요 기능:
- 조회 방식, 연도, 월, 시작 월, 종료 월, 근무지, 직원명으로 수당 현황을 조회한다.
- `기간 직접 지정`을 선택하면 시작 월과 종료 월을 달력형 월 선택기로 지정한다.
- KPI 카드에서 총 수당, 총 근무시간, 승인 상태, 주요 변동을 확인한다.
- 월별 수당 지급 추이, 근무지별 수당 현황, 근무 유형별 상위 인원, 수당 유형 비율을 확인한다.
- 현재 필터 기준 결과를 PDF 또는 Excel로 내보낸다.

사용 기준:
- 월별 운영 상태를 볼 때는 연도와 월을 먼저 고정한다.
- 여러 월을 비교할 때는 `기간 직접 지정`을 사용한다.
- 내보내기 전 현재 필터와 화면 결과가 원하는 범위인지 확인한다.

## 인력 관리
주요 기능:
- 인력 목록을 근무지, 재직 상태, 배정 상태, 이름 또는 사원번호로 조회한다.
- 신규 인력을 등록하고 고용형태, 상태, 근무지 배정, 조, 최초 시급, 적용일을 저장한다.
- 인력 상세에서 현재 프로필, 근무변경이력, 시급변경이력을 확인한다.
- Excel 파일로 시급 일괄 업데이트를 실행한다.

사용 기준:
- 시급은 적용 시작일 기준 이력으로 관리한다.
- 시급 일괄 업데이트는 파일 선택, 열 매핑, 미리보기, 최종 반영 순서로 진행한다.
- 동명이인이 있을 수 있으므로 이름 검색만으로 확정하지 말고 사원번호를 함께 확인한다.

## 근무지 관리
주요 기능:
- 등록된 근무지 목록과 운영 상태, Cycle, 교대 구조, 조 현황을 확인한다.
- 1단계에서 근무지 기본 정보, 사이트 명, 조 수, Cycle 수, 근무 패턴, Pool 기준을 저장한다.
- 2단계에서 후보 인력을 조별로 배정한다.
- 상세 보기에서 저장된 Cycle, 근무시간, 조별 인원, Pool 기준을 재확인한다.
- 표준 근무표 Excel을 분석해 패턴 적용된 근무지 draft를 생성한다.

사용 기준:
- 근무표 배포와 실적 파싱은 근무지의 근무 패턴, 조 배정, 저장된 월간 근무표를 기준으로 연결된다.
- 품의서에서 고객사명과 근무지명을 분리해야 하면 근무지 등록 단계에서 `사이트 명`을 지정한다.

## 근무표 배포
주요 기능:
- 배포 대상 연도, 월, 근무지, 근무표 양식을 선택한다.
- 월간 달력과 근무조 편성 결과를 확인한다.
- 배포 대상, 제외 인원, 근무 패턴 반영 상태를 확인한다.
- Excel 근무표를 지정된 근무표 출력 폴더로 저장한다.
- 배포 이력에서 최근 파일명과 저장 경로를 확인한다.

사용 기준:
- 실적 파일은 저장된 월간 근무표를 기준으로 법정휴일근무와 대체근무 시간을 복원한다.
- 실적 승인 전에 해당 월과 근무지의 근무표 배포 이력이 있는지 먼저 확인한다.

## 실적 관리
주요 기능:
- 승인 대기 폴더의 실적 파일 목록을 조회한다.
- 실적 파일을 파싱해 법정휴일근무, 대체근무, 연장근무 행을 확인한다.
- 각 실적 행을 승인하면 수당 산출 결과가 즉시 생성된다.
- 모든 승인 대상 행이 승인되면 파일을 승인 완료 폴더로 이동하고 유효본으로 표시한다.
- 재승인 파일은 변경 가능 행을 현재 파일 기준으로 다시 승인한 뒤 `재승인 확정`으로 반영한다.

운영 규칙:
- 같은 근무지, 같은 사번, 같은 근무일의 근무시간은 겹칠 수 없다.
- 동명이인은 파싱 단계에서 근무지와 근무일 기준으로 사번을 먼저 확정한다.
- 같은 이름이 같은 근무지에서 여러 사번으로 남아 사번을 확정할 수 없으면 오류 알림으로 승인되지 않는다.
- Pool 근무자의 대체근무는 실적 기록에는 남지만 수당 승인과 산출 대상에서 제외된다.
- `품의승인` 상태 수당과 연결된 행은 변경불가로 표시된다.

## 수당 관리
주요 기능:
- 승인된 실적에서 생성된 수당 산출 결과를 조회한다.
- 수당 상태를 `검토대기`, `승인`, `반려`, `품의승인` 기준으로 관리한다.
- 근무지 단위 `근무지 승인`, `근무지 반려`를 실행한다.
- 행 단위 상세에서 시급, 근무시간, 기본/연장/야간 수당 계산 내역을 확인한다.
- 퇴직자 선지급 대상 행에 선지급 날짜를 등록한다.
- 승인된 수당을 기준으로 품의서, 별첨1, 별첨2를 PDF 또는 Excel로 출력한다.
- `품의 승인`에서 승인 대상, 지급 합계, 정규 지급, 선지급 금액을 미리 확인하고 최종 마감한다.
- `품의 이력`에서 수당 승인 이력, 문서 출력 이력, 최종 품의 승인 기록을 조회한다.

운영 규칙:
- `근무지 반려`는 반려 사유 입력이 필수다.
- `품의승인` 상태 수당이 포함된 근무지는 `근무지 반려`를 실행할 수 없다.
- 품의 승인 완료 시 문서 출력, 품의 승인 기록 저장, 자동 DB 백업이 함께 실행된다.
- 품의 승인 중 DB 반영이 실패하면 출력 문서와 백업 파일은 남을 수 있으므로 출력 경로와 백업 폴더를 확인한 뒤 다시 시도한다.

## 운영 관리
운영 관리는 관리자 전용 기준정보 메뉴다.

### 경로 설정
- 승인 대기 폴더, 승인 완료 폴더, 근무표 출력 폴더, 품의서/별첨 출력 폴더를 저장한다.
- DB 자동 백업 폴더, 백업 주기, 백업 시간을 저장한다.
- `수동 백업`으로 현재 운영 DB를 JSON과 Excel로 백업한다.
- Access 원본 경로가 확인되면 `.accdb` 사본도 함께 백업한다.
- `DB업데이트`로 JSON 백업 파일 또는 Access DB 기준 복원을 실행한다.

### 공휴일 관리
- 연도별 공휴일 캘린더와 공휴일 항목을 조회한다.
- 외부 API 기준 공휴일을 불러와 저장 목록과 비교한다.
- 필요한 연도 공휴일을 시스템 DB에 반영한다.

### 요율 관리
- 연도별 수당 계산 요율 버전을 등록, 수정, 삭제한다.
- 요율 적용 시 변경 사유를 입력한다.
- 변경 사유와 적용 이력은 최근 요율 변경 이력과 활동 이력에 남는다.
- 이미 계산 이력에 사용된 요율은 임의 삭제할 수 없다.

### 사용자 관리
- 운영 계정을 등록, 수정, 삭제한다.
- 사용자 역할은 관리자와 사용자로 구분한다.
- 상태값으로 사용중, 중지, 대기 계정을 관리한다.

### 사이트 명 관리
- 근무지 등록 1단계에서 선택할 사이트 명 값을 등록한다.
- 품의서 출력에서 고객사명과 근무지명을 분리하는 기준으로 사용한다.
- 사용 중인 사이트 명은 삭제보다 수정으로 관리한다.

### 양식 관리
- 근무표, 품의서, 별첨1, 별첨2 양식을 등록한다.
- 구조 확인 후 도식 미리보기와 속성 패널에서 문서 영역을 조정한다.
- 고급 모드에서 셀 범위, 행, 열, 색상, 병합 기준을 보정한다.
- 검증 출력 후 저장하고, 승인된 양식만 실제 배포와 문서 출력에서 선택할 수 있다.
- 승인된 양식 중 `기본 사용` 양식이 자동 선택 기준이 된다.

## 활동 이력
주요 기능:
- 로그인, 화면 이동, 실적 승인, 수당 승인, 수당 반려, 품의 미리보기, 품의 승인, 문서 출력 등 주요 작업 기록을 조회한다.
- 조회 시작일, 조회 종료일, 사용자, 액션 유형, 검색어로 필터링한다.
- 처리 시각, 사용자, 액션, 대상 메뉴, 상세 내용을 확인한다.

사용 기준:
- 일일 점검 시 최근 승인, 반려, 품의 승인 이력을 조회한다.
- 이상 작업이 의심되면 사용자와 날짜 범위를 먼저 좁히고 액션 유형을 추가로 지정한다.

## 일일 점검 체크리스트
- 대시보드에서 대상 월 또는 기간의 총 수당과 근무지별 수당 현황을 확인한다.
- 실적 관리에서 승인 대기 파일과 오류 알림이 남아 있는지 확인한다.
- 수당 관리에서 검토대기, 반려, 품의 승인 대기 건을 확인한다.
- 품의 이력에서 최근 품의 승인 기록과 백업 경고 여부를 확인한다.
- 운영 관리 경로 설정과 DB 백업 경로가 현재 운영 경로와 맞는지 확인한다.
