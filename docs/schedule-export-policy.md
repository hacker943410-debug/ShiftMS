# 근무표 배포 파일 정책

작성일: 2026-03-11

이 문서는 근무표 배포용 xlsx 파일 생성 및 승인완료 폴더 게시 시의 파일명 처리 정책을 고정한다.

## 1. 생성 경로

1. 근무표 생성 결과는 기본적으로 `scheduleExportDir`에 저장한다.
2. 파일명 기본 형식은 `근무지_배포월_패턴명.xlsx`다.

## 2. 게시 경로

1. 게시 대상은 앱 설정의 `approvedDir`이다.
2. 게시는 생성된 원본 파일을 승인완료 폴더로 복사하는 방식으로 처리한다.

## 3. 충돌 정책

1. 기존 파일이 이미 존재하면 조용한 덮어쓰기를 금지한다.
2. 같은 이름이 있으면 파일명 뒤에 `_dup01`, `_dup02` 같은 suffix를 붙여 새 파일을 만든다.
3. 어떤 파일이 실제 게시되었는지는 `schedule_plan_exports.published_path`에 저장한다.

## 4. 이력 정책

1. xlsx 생성 시 `schedule_plan_exports`에 생성 이력을 남긴다.
2. 게시 완료 시 같은 이력의 `publish_status`, `published_path`를 갱신한다.
