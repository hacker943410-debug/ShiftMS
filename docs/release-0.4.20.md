# ShiftMgmt 0.4.20

법정공휴일 실적 복구 및 재승인 알림 정상화

월간 근무표가 비어 0분으로 누락되던 법정공휴일·대체근무 실적을 자동 복구하고, 승인하지 않은 근무지에 재승인 알림이 반복되던 문제를 출처 기준 판정으로 바로잡았습니다.

> 이 업데이트는 시작 시 기존 승인 실적을 정정·보강합니다. 적용 전 데이터 백업을 권장합니다.

## 실적 복구
- **월간 근무표 자동 복구** — 앱 시작 시 배포관리 근무표를 다시 읽어 비어 있던 월간 근무표를 복구하고, 기존 승인 실적은 정정값으로 다시 맞춰 불필요한 재승인을 막습니다.
- **법정공휴일 시간 집계** — 근무표 정보가 없어 0분으로 떨어지던 법정공휴일·대체근무 시간을 정상 집계합니다.

## 승인 판정
- **출처 기준 재승인** — 파서 계산식만 바뀐 경우에는 재승인을 요구하지 않고, 실제 근무 원본이 바뀐 경우에만 재승인을 표시합니다.
- **손상 스냅샷 표면화** — 승인 증거를 읽을 수 없을 때 해당 항목만 재검토로 안내하고 다른 근무지에는 영향을 주지 않습니다.

## 실적 파싱
- **투입 인원 인식** — `-`로 비어 있던 자리에 인원을 새로 투입하면 해당 실적을 정상 인식합니다.

## 후속 보강 예정
- 부팅 복구의 재승인 방지에 대한 종단 검증 테스트 보강
- 출처 기준 수당 변경 재승인 통합 테스트(Test C) 추가
