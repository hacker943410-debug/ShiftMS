# 수당 요율 연도 버전 정책

작성일: 2026-03-11

이 문서는 수당 요율의 연도별 버전 관리 기준을 정의한다. 목적은 승인 시점 재현성과 후속 재계산 분쟁을 방지하는 데 있다.

## 1. 기본 원칙

1. 요율은 연도 기준 버전 엔터티로 관리한다.
2. 승인 시점에는 반드시 적용된 요율 버전 ID를 스냅샷에 저장한다.
3. 같은 연도 안에서도 개정이 발생할 수 있으므로 `year`만으로는 충분하지 않다.
4. 실제 선택 기준은 `effective_from`, `effective_to`, `status`를 함께 본다.

## 2. 상태 정의

- `draft`
  작성 중이며 계산에 사용하지 않는다.
- `active`
  승인 및 계산에 사용할 수 있는 버전
- `retired`
  신규 계산에는 사용하지 않지만 과거 스냅샷 재현에는 남겨둔다.

## 3. 선택 규칙

1. 계산일 또는 승인일이 `effective_from <= target_date <= effective_to` 범위에 들어야 한다.
2. `effective_to`가 비어 있으면 개방 구간으로 본다.
3. `status`가 `active`인 버전만 신규 계산 후보가 된다.
4. 같은 날짜에 여러 `active` 버전이 겹치면 가장 최근 `effective_from`을 우선한다.
5. 승인 완료 후에는 새 active 버전이 생겨도 기존 승인 스냅샷은 바꾸지 않는다.

## 4. 예시

| year | version | status | effective_from | effective_to |
| --- | --- | --- | --- | --- |
| 2026 | 2026.1 | retired | 2026-01-01 | 2026-06-30 |
| 2026 | 2026.2 | active | 2026-07-01 |  |

위 경우:

1. `2026-03-15` 계산은 `2026.1`
2. `2026-08-01` 계산은 `2026.2`
3. `2026.1`로 승인된 결과는 이후에도 `2026.1` 기준으로 재현한다.

2. 요율 중복 구간 검증 추가
3. 요율 버전 선택 결과를 승인 스냅샷과 연결
