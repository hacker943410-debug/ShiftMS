## 제품 개요
`0.4.6`은 패치노트가 한 버전만 보여 중간 버전을 놓치던 문제를 정리한 릴리즈다. 이번 버전부터는 마지막으로 확인한 버전 이후의 패치노트를 모두 순서대로 확인해야 하며, 운영 관리에서 버전별 변경사항을 검색하고 필터링할 수 있다.

## 이번 릴리즈 핵심 변경

### 1. 패치노트 강제 확인 범위 확대
- 마지막 확인 버전 이후부터 현재 버전까지의 패치노트를 모두 묶어서 표시한다.
- 패치노트 하단에 `이전`, `다음`, `모든 패치 확인 완료` 버튼을 두어 버전별로 확인할 수 있게 했다.
- 마지막 페이지까지 확인해야 `패치노트 확인 완료`로 저장된다.

### 2. 패치노트 표현 방식 개편
- 운영자가 바로 이해할 수 있는 표현으로 문구를 다시 정리했다.
- 변경사항은 번호 목록으로 정리하고, 비교가 필요한 내용은 표로 표시한다.
- 업데이트 안내 모달도 새 매니페스트 포맷을 읽어 핵심 변경을 더 정확하게 보여준다.

### 3. 운영 관리 `패치이력` 메뉴 추가
- `운영 관리 > 패치이력` 메뉴를 추가했다.
- 필터는 `업데이트 구분`, `적용 조건`을 제공한다.
- 검색은 공백, 구분자, 대소문자 차이를 무시하는 정규화 검색으로 동작한다.

### 4. 기존 설치 업데이트 시 운영 데이터 보존
- 기존 설치가 있는 PC에서 설치 프로그램을 다시 실행하면 업데이트 안내 흐름으로 진입한다.
- 설치 전 사용자 데이터 폴더를 백업하고 설치 후 자동 복원해 계정정보와 DB가 초기화되지 않도록 정리했다.

## 표시 기준 변경표
| 구분 | 이전 | 0.4.6 변경 |
|---|---|---|
| 패치 확인 범위 | 현재 버전 1건만 표시 | 놓친 버전 전체를 순서대로 확인 |
| 이동 방식 | 확인 버튼 1개 | 이전 / 다음 / 최종 확인 버튼 |
| 내용 표현 | 단순 목록 위주 | 설명 카드 + 번호 목록 + 표 |
| 운영 조회 | 별도 메뉴 없음 | 운영 관리 `패치이력` 메뉴 제공 |
