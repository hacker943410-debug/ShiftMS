# ShiftMgmt 0.4.22

대량 품의서 별첨1 병합 충돌 수정 및 폴더 감시 안정화

별첨1 정규 요약이 템플릿 용량을 초과해 행이 삽입될 때 발생하던 병합 충돌로 대량 항목 품의서 출력이 실패하던 문제를 수정하고, 폴더로 복사 중인 파일이 부분 저장 상태로 읽히지 않도록 감시 안정화를 추가했습니다.

## 별첨1 Excel
- **행 삽입 前 병합 정리** — 정규 요약이 템플릿 용량(10행)을 초과해 `spliceRows`로 행이 삽입되기 전에 선지급 헤더 영역(19-21행)의 잔존 병합을 먼저 해제합니다. 옮겨지지 않은 `A19:A21` 병합이 새 헤더 `A21:A23`과 겹쳐 `Cannot merge already merged cells`로 출력이 실패하던 원인을 제거했습니다.
- **헤더 재작성 방어** — 헤더 병합 직전에도 대상 범위의 잔존 병합을 정리해 행 삽입·삭제 양쪽 경로를 보호합니다(품의서의 before/after 패턴과 동일).
- **0.4.21 보완** — 0.4.21은 행 제거 경로만 다뤘고, 본 패치가 행 삽입 경로의 잔존 충돌까지 마감했습니다.

## 폴더 감시
- **쓰기 완료 대기** — 감시 폴더에 들어온 파일의 크기가 2초간 안정된(`awaitWriteFinish`) 뒤에만 처리해, 네트워크/폴더 복사 도중의 부분 저장본을 파싱하지 않습니다.
- **기존 파일 처리 불변** — 시작 시 기존 파일은 종전대로 startup 동기화가 담당하고, 감시는 라이브 드롭만 안정화 후 처리합니다.
