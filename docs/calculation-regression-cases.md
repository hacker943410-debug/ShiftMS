# 계산 회귀 테스트 기준 초안

작성일: 2026-03-11

이 문서는 근로시간 계산 및 수당 계산 엔진의 회귀 테스트 기준을 고정하기 위한 초안이다. 실제 계산식 구현 전에 기대값을 먼저 정리한다.

## 1. 공통 기준

1. 날짜 형식은 `YYYY-MM-DD`
2. 시각 형식은 `HH:mm`
3. 시간 단위 저장은 분(minute)
4. 자정 넘김을 허용한다.
5. 휴게시간은 총 근로시간에서 차감한다.
6. 승인 시점 계산 스냅샷은 이후 재계산과 별도 버전으로 보존한다.

## 2. 계산 항목 초안

- 총 근로시간
- 기본근로시간
- 연장근로시간
- 야간근로시간
- 휴일근로시간
- 대체근로시간
- 수당 항목별 금액

## 3. 반올림 정책 초안

아래 정책은 확정 전 초안이다.

1. 시간 계산은 분 단위 정수로 유지한다.
2. 금액 계산은 원 단위 정수로 계산한다.
3. 배수 적용 후 소수점이 생기면 `round-half-up` 또는 `floor` 중 하나로 확정이 필요하다.
4. UI 포맷은 원시 계산값 이후 단계에서만 적용한다.

## 3.1 현재 코드에 반영한 임시 가정

아래 규칙은 이번 단계에서 shared 순수 함수와 테스트를 고정하기 위해 임시 반영했다.

1. 기본근로시간 상한은 1일 `480분`으로 둔다.
2. 연장근로시간은 `총 근로시간 - 480분`으로 계산한다.
3. 휴일근로는 우선 총 근로시간 전체를 `holidayMinutes`로 적재한다.
4. 야간근로시간은 `22:00~06:00` 구간의 겹침 시간으로 계산한다.
5. 휴게시간이 야간시간에 어떻게 배분되는지는 아직 확정하지 않았으며, 현재 구현은 "순근로시간을 초과하지 않음" 수준으로만 제한한다.
6. 수당 금액 계산은 현재 `시급 x (분 / 60) x 배수` 후 `Math.round`를 적용한다.

## 4. 우선 테스트 케이스

### Case 01. 동일 일자 주간 기본근무

- 설명: 자정 넘김 없는 기본 주간 근무
- 입력:
  - 근무일: `2026-03-02`
  - 시작: `09:00`
  - 종료: `18:00`
  - 휴게: `60`
- 기대:
  - 총 근로시간: `480`
  - 기본근로시간: `480`
  - 연장근로시간: `0`
  - 야간근로시간: `0`

### Case 02. 연장근로 포함 주간근무

- 설명: 기본 8시간 초과분이 연장근로로 분리되는 케이스
- 입력:
  - 근무일: `2026-03-03`
  - 시작: `09:00`
  - 종료: `20:00`
  - 휴게: `60`
- 기대:
  - 총 근로시간: `600`
  - 기본근로시간: `480`
  - 연장근로시간: `120`
  - 야간근로시간: `0`

### Case 03. 자정 넘김 야간근무

- 설명: 자정을 넘기는 야간 근무
- 입력:
  - 근무일: `2026-03-04`
  - 시작: `22:00`
  - 종료: `06:00`
  - 휴게: `60`
- 기대:
  - 총 근로시간: `420`
  - 야간근로시간: `420`

### Case 04. 주간과 야간이 혼합된 연장근무

- 설명: 저녁부터 익일 새벽까지 이어지는 근무
- 입력:
  - 근무일: `2026-03-05`
  - 시작: `18:00`
  - 종료: `04:00`
  - 휴게: `60`
- 기대:
  - 총 근로시간: `540`
  - 기본근로시간: `480`
  - 연장근로시간: `60`
  - 야간근로시간: `360`

### Case 05. 휴게시간이 큰 야간근무

- 설명: 휴게시간이 야간 구간에 포함되는 경우
- 입력:
  - 근무일: `2026-03-06`
  - 시작: `21:00`
  - 종료: `07:00`
  - 휴게: `120`
- 기대:
  - 총 근로시간: `480`
  - 야간근로시간: 휴게 차감 정책 명시 필요

현재 상태:

- 회귀 테스트에는 아직 포함하지 않음

### Case 06. 법정공휴일 주간근무

- 설명: 공휴일 캘린더에 포함된 날짜의 근무
- 입력:
  - 근무일: `2026-03-01`
  - 공휴일 여부: `true`
  - 시작: `09:00`
  - 종료: `18:00`
  - 휴게: `60`
- 기대:
  - 총 근로시간: `480`
  - 휴일근로시간: `480`

### Case 07. 공휴일 + 연장근무

- 설명: 공휴일 근무가 8시간을 초과하는 경우
- 입력:
  - 근무일: `2026-03-01`
  - 공휴일 여부: `true`
  - 시작: `09:00`
  - 종료: `21:00`
  - 휴게: `60`
- 기대:
  - 총 근로시간: `660`
  - 휴일근로시간: `660`
  - 연장 분리 정책 추가 확정 필요

현재 상태:

- 총 근로시간과 휴일근로시간까지만 회귀 테스트에 포함

### Case 08. 대체근로 태그 케이스

- 설명: 근무 유형이 대체근로로 분류되는 경우
- 입력:
  - 근무일: `2026-03-08`
  - work_type: `substitute`
  - 시작: `09:00`
  - 종료: `18:00`
  - 휴게: `60`
- 기대:
  - 총 근로시간: `480`
  - 대체근로시간: `480`

### Case 09. 24시간 미만 자정 넘김 검증

- 설명: 종료 시간이 시작 시간보다 이르지만 정상 자정 넘김으로 해석되어야 하는 케이스
- 입력:
  - 시작: `23:30`
  - 종료: `02:30`
  - 휴게: `30`
- 기대:
  - 총 근로시간: `150`

### Case 10. 승인 스냅샷 재현성

- 설명: 동일 입력과 동일 요율 버전으로 재계산 시 동일 결과가 나와야 한다.
- 입력:
  - 승인 시점 원본 실적
  - 동일 공휴일 캘린더
  - 동일 요율 버전
- 기대:
  - 총 근로시간 동일
  - 수당 항목별 금액 동일
  - 스냅샷 해시 동일

현재 상태:

- 스냅샷 구조만 정의
- 금액 계산 스냅샷 생성 함수까지 반영
- 해시 정책은 후속 작업
