# ShiftMgmt 0.5.2

품의서·별첨1 출력 오류 수정 + 구버전 품의서 양식 허용

이번 업데이트는 **수당 문서 출력의 오류 수정**과 **실적 불러오기의 안전장치 보강**입니다. 계산 규칙과 승인된 데이터는 바뀌지 않으며, 업데이트로 인한 재승인은 발생하지 않습니다.

## 품의서·별첨1 출력 안정화
- **품의서 셀 병합 오류 수정** — 근무지가 두 곳 이상이면 표에 줄을 끼워 넣는데, 이때 "붙은 칸" 정보가 낡은 위치로 남아 `이미 병합된 셀` 오류로 멈추던 것을 뿌리부터 고쳤습니다. 근무지 0~7곳 조합을 자동 시험으로 확인했습니다.
- **별첨1 유령 병합 수정** — 별첨1은 같은 원인으로 오류 창 없이 안내문 구역에 잘못된 병합 띠가 박힌 파일이 나올 수 있었습니다. 명단 수와 상관없이 정확한 위치에만 병합이 생기도록 고쳤습니다.
- **구버전 품의서 양식 허용** — 구버전(2026-04 이전) 품의서 양식도 등록할 수 있습니다. 등록 시 "구버전으로 인식했다"는 안내가 뜨고, 출력할 때 줄 위치를 자동으로 한 줄 맞춰 최신 양식과 같은 내용으로 채웁니다.

## 실적 불러오기 안전장치
- **연장근무 시각 오타 보호** — 연장근무 시각에 잘못된 값(예: 25시)을 적으면 하루 전체(24시간) 근무로 계산될 수 있던 구멍을 막았습니다. 이제 0분으로 잡히고 경고가 떠서, 시각을 고쳐 다시 넣기 전까지 수당이 발생하지 않습니다. 올바르게 적은 시각의 계산은 그대로입니다.

## 안전성
- **계산·승인 불변** — 정상 데이터의 계산 결과는 전혀 바뀌지 않습니다. 문서 출력과 잘못된 입력의 처리만 고쳤습니다.
- **재발 방지** — 엑셀 불러오기 규칙 47가지를 전수 점검하고 자동 시험 22개를 추가했습니다. 한계 상황(연장 62행, 휴일 31일, 대기 파일 23개, 90일×24명 패턴)도 통과를 확인했습니다.
