# 운영자 빠른 시작 가이드

## 목적
ShiftMgmt_V3.4는 교대근무 운영자가 인력 현황, 근무표 배포, 실적 승인, 수당 계산, 문서 출력을 하나의 로컬 앱에서 처리하도록 만든 Electron 데스크톱 앱이다.

## 최초 사용 전 준비
1. 앱에 로그인한다.
2. `운영 관리 -> 경로 설정`에서 아래 경로를 저장한다.
   - 승인 대기 폴더
   - 승인 완료 폴더
   - 근무표 내보내기 폴더
   - 품의서 저장 폴더
   - 별첨1 저장 폴더
   - 별첨2 저장 폴더
   - 마이그레이션 파일 경로
     - Access `.accdb` 또는 백업 JSON `.json`
3. `공휴일 관리`, `요율 관리`, `사용자 관리`, `양식 관리`가 현재 운영 기준과 맞는지 확인한다.
4. 릴리즈 직전 검수는 `docs/operations-manual-qa-checklist.md` 기준으로 별도 기록한다.

## 일상 운영 흐름

### 1. 인력 및 근무지 기준정보 정리
- `인력 관리`에서 인력 기본정보, 근무지 배정, 시급 이력을 확인한다.
- `근무지 관리`에서 패턴, 조 배정, 정원 구성을 확인한다.

### 2. 근무표 배포
- `근무표 배포`에서 대상 월과 근무지를 선택한다.
- 승인된 근무표 양식을 선택해 배포한다.
- 배포 결과는 저장 경로와 이력에서 다시 확인한다.

### 3. 실적 승인
- `실적 관리`에서 승인대기 파일을 확인한다.
- 최초 승인 완료 시 파일은 자동으로 승인 완료 폴더로 이동한다.
- 재승인이 필요하면 승인 완료 폴더의 파일을 사용자가 다시 승인 대기 폴더로 옮긴다.
- 재승인 대상은 `재승인 대기`, 재승인한 행은 `재승인 완료` 상태로 표시된다.
- 파일 전체를 최종 반영할 때는 `재승인 확정`을 사용한다.

### 4. 수당 계산 및 문서 출력
- `수당 관리`에서 승인 실적을 기준으로 수당을 산출한다.
- 퇴직자 선지급이 필요하면 대상 행에서 선지급 날짜를 등록한다.
- 품의서, 별첨1, 별첨2는 Excel/PDF로 출력할 수 있다.
- 문서는 운영 관리에서 저장한 경로로 저장된다.

### 5. 운영 관리 유지보수
- `공휴일 관리`에서 저장 목록과 API 목록을 비교해 반영한다.
- `요율 관리`에서 연도별 요율 버전을 관리한다.
- `사용자 관리`에서 운영 계정을 생성, 수정, 삭제한다.
- `양식 관리`에서 양식을 등록, 승인, 기본 사용 전환한다.
- 기준정보를 백업본이나 Access 원본으로 되돌릴 때는 `운영 관리 -> 경로 설정`에서 마이그레이션 파일을 지정한 뒤 우측 상단 `DB업데이트`를 실행한다.
- `DB업데이트`를 누르면 먼저 현재 DB 현황과 업데이트 후 예상 현황을 비교하는 미리보기 모달이 열린다.
- 미리보기 모달에서 변경될 건수와 대상 파일을 다시 확인한 뒤 `승인`을 눌러 실제 교체를 실행한다.
- 실행이 끝나면 같은 모달에서 업데이트 결과와 최종 DB 상태를 다시 확인한다.
- Access `.accdb` 복원은 기준정보뿐 아니라 `사업조직별근무실적` 기반 기본 승인/수당 이력도 함께 이관한다.

## 현재 운영 규칙
- Pool 근무자가 수행한 대체근무는 실적 기록에는 남지만 실적 관리 화면과 수당 산출에서는 제외한다.
- 수당 계산은 승인 시점의 저장 스냅샷만 기준으로 재현한다.
- 재승인 확정 시 엑셀 파일 자체를 수정하지 않고 DB의 최신 승인 이력을 기준으로 반영한다.

## 권장 일일 점검
- `대시보드`에서 승인 대기와 수당 집계를 먼저 확인한다.
- `실적 관리`에서 승인 대기 파일이 남아 있는지 확인한다.
- `수당 관리`에서 미산출 승인 실적과 출력 이력을 확인한다.
- `운영 관리 -> 경로 설정`이 바뀌지 않았는지 확인한다.
