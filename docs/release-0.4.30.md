# ShiftMgmt 0.4.30

공휴일 누락 자동승인 방지, 손이동 파일 복구, 승인대기 되돌리기

이번 업데이트는 `0.4.29` 후속으로, 공휴일 근무가 빠진 채 실적이 자동으로 승인완료로 묻혀버리던 문제를 막고, 승인 파일을 손으로 옮겨 재승인이 막히던 상태를 복구하며, 승인완료 파일을 승인대기로 되돌리는 정식 기능을 추가합니다. 모든 변경은 기존 승인 데이터의 식별 방식을 바꾸지 않아 업데이트 후 대량 재승인이 발생하지 않습니다.

## 실적 승인 보호
- **공휴일 누락 시 자동승인 보류** — 그 달 공휴일이 등록돼 있는데 그 날짜에 잡힌 실적 행이 하나도 없으면(근무표의 공휴일 표시가 빠진 신호), 연장근무만 승인해도 자동으로 승인완료로 넘기지 않고 승인대기에 둡니다. 연장근무 승인 자체는 그대로 유지됩니다.
- **날짜 기준 판단** — 등록된 공휴일 날짜와 실제 실적 행의 날짜를 비교하므로, 공휴일에 실제로 일했거나(대체근무 포함) 일이 다음 달로 이어지는 정상 경우에는 보류 없이 평소처럼 처리됩니다.
- **이대로 승인완료** — 정말 공휴일 근무가 없었다면 안내 영역의 "이대로 승인완료"로 그대로 마무리할 수 있습니다. 수당 승인 경로에서도 같은 보호가 적용됩니다.

## 막힘 복구와 되돌리기
- **손이동 파일 재승인 복구** — 승인완료 파일을 탐색기로 직접 옮겨 재승인이 영영 막히던 상태를 앱이 알아채고 다시 승인할 수 있게 풀어줍니다.
- **오프라인 폴더 보호** — 네트워크·클라우드 승인완료 폴더가 잠깐 끊겼을 때 멀쩡한 파일을 잘못 푸는 일이 없도록 안전장치를 넣었습니다.
- **승인대기로 되돌리기 버튼** — 승인완료 화면에서 파일을 처음 받은 것처럼 깨끗하게 승인대기로 되돌릴 수 있습니다(이전 승인 기록 정리, 같은 파일로 유지). 수당 품의까지 승인된 파일은 안전을 위해 막습니다.

## 안전성
- **식별자 불변** — 파일·실적 행 식별 방식과 승인 비교 기준을 바꾸지 않아 기존 승인완료본이 업데이트 후 재승인 대상으로 잘못 표시되지 않습니다.
- **되돌리기 원자 처리** — 승인대기 되돌리기는 한 묶음으로 처리되어 중간에 멈춰도 데이터가 어중간하게 남지 않습니다.
