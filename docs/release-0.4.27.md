# ShiftMgmt 0.4.27

실적관리 조별 검수, 반려 재파싱, None 취소 처리 안정화

이번 업데이트는 실적관리 검수 화면을 조별로 정리하고, 반려 상태의 승인대기 파일이 실제 Excel 기준으로 다시 분석되도록 보정합니다. 로그인 실패 5회 계정 잠금도 제거했습니다.

## 실적관리 검수
- **조별 묶음 표시** — 근무지 아래에 조별 요약 행을 추가해 승인, 대기, 반려, 재검토, 알림 건수를 조 단위로 확인합니다.
- **조 정보 저장** — 실적 엔트리에 근무표의 `teamLabel`을 저장해 재조회 후에도 조별 정렬과 묶음이 유지됩니다.
- **조 우선 정렬** — 실적 목록은 조를 먼저 기준으로 정렬하고, 같은 조 안에서 근로유형, 일자, 이름 순서를 적용합니다.

## 반려 파일 재파싱
- **반려 대기 파일 재분석** — 승인대기 폴더의 반려 파일은 파일 크기와 수정 시간이 같아도 기존 분석 결과를 재사용하지 않고 다시 파싱합니다.
- **수동 이동 복구성 개선** — 승인완료 파일을 로직 밖에서 승인대기 폴더로 옮긴 경우에도, 화면 조회 시 현재 Excel 내용 기준으로 법정휴일, 대체, 연장 실적을 복구합니다.

## None 취소 처리
- **변경표 None 취소 연결** — 변경/대체 표에서 `원근무자 -> None`으로 입력된 경우 같은 일자의 원근무자 법정휴일 실적을 생성하지 않습니다.
- **기존 슬롯 None 유지** — 원근무자 셀 자체가 `None`이거나 같은 슬롯의 변경 후 셀이 `None`인 기존 취소 동작은 유지합니다.
- **중복 경고 감소** — 취소된 원근무자를 실적 행으로 만들지 않아 0시간 행과 불필요한 중복 경고 노출을 줄입니다.

## 인증 정책
- **계정 잠금 제거** — 로그인 비밀번호를 5회 이상 틀려도 계정을 잠그지 않습니다.
- **감사 기록 유지** — 실패 횟수는 접근 이력과 운영 확인용으로 남기되, 잠금 해제 절차는 요구하지 않습니다.

## 운영 참고
- 승인/반려 후에는 폴더 직접 이동 대신 앱의 반려/승인 흐름을 사용해야 DB 상태, 승인 이력, 파일 위치가 함께 맞습니다.
- 이미 수동 이동된 승인대기 파일은 이번 버전에서 해당 월 조회 또는 새로고침을 실행하면 현재 Excel 기준으로 다시 분석됩니다.
