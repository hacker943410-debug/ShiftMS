## 제품 개요
교대근무관리시스템 `0.4.11`은 `0.4.10` 실적 파싱 안정화 기준선 위에서 실적관리 조회 범위를 더 엄격하게 제한한 패치 릴리즈다.

## 이번 릴리즈 핵심 변경

### 1. 승인완료 조회 범위 제한
- 실적관리 `조회구분`에서 `승인완료 보관본`을 조회할 때 연도와 월 선택을 필수로 바꿨다.
- 연도/월이 없는 승인완료 요청은 백엔드에서 전체 폴더 스캔 없이 빈 결과와 안내만 반환한다.
- 승인완료 월 조회 중 재승인 후보 확인이 필요한 경우에도 선택 월의 승인대기 폴더만 함께 확인한다.

### 2. 조회구분 정리
- 실적관리 `조회구분`의 `전체` 항목을 제거했다.
- 조회구분 타입도 `승인대기`와 `승인완료 보관본`만 허용하도록 정리했다.
- 실적관리 진입 기본값은 `승인대기`로 유지한다.

### 3. 승인대기 실제 파일 기준 표시
- DB에 과거 승인대기 실적이 남아 있어도 실제 승인대기 폴더에 파일이 없으면 실적관리 목록에 표시하지 않는다.
- 월별 승인대기 조회 시 대상 폴더가 비어 있거나 파일이 이동된 경우 stale DB 행을 정리한다.
- 변경 없는 승인대기/승인완료 Excel은 기존 분석 결과를 재사용해 재파싱 부담을 줄인다.
