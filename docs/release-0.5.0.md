# ShiftMgmt 0.5.0

근무지 화면 전면 개편 · 평일/휴일 시간 분리 · 정확도·보안 강화

이번 업데이트는 `0.4.30` 후속의 큰 개편입니다. 근무지 등록·수정 1·2단계 화면을 짧은 단계로 새로 짜 훨씬 쉽고 보기 편하게 했고, 평일과 휴일의 근무시간을 따로 설정할 수 있게 했습니다. 여기에 공휴일·대체근무·수당 요율 계산의 정확도와 로그인 보안을 함께 강화했습니다. 계산과 관련된 변경은 모두 이미 승인된 자료를 다시 바꾸지 않는 방식(앞으로의 계산만 정확해짐)이라 업데이트 후 대량 재승인이 발생하지 않습니다.

## 근무지 화면 개편
- **단계 분할** — 1단계를 `① 기본 설정 → ② 근무 시간 설정`으로 나눠, 한 화면에 몰려 있던 입력을 단계별로 나눴습니다. 시간 편집은 접었다 펼치는 방식으로 바꿔 끝없이 길던 스크롤을 크게 줄였습니다.
- **미리보기 고정** — 입력 옆 미리보기 달력이 노트북 화면에서도 무너지지 않고 항상 옆에 붙어 따라다닙니다.
- **자주 쓰는 패턴으로 시작** — 주간 전담·격일제(2조)·3조 2교대·4조 3교대 중 하나를 고르면 조 수·교대·근무시간·패턴이 한 번에 채워집니다. 적용 후 달력으로 확인하고 자유롭게 수정할 수 있습니다.
- **클릭 배정** — 2단계 인력 배정을 드래그뿐 아니라 `조 선택해 배정`·`해제` 버튼으로도 할 수 있습니다. 조 칸이 좁은 화면에서도 나란히 보이고, 조별 정원 채움이 막대로 표시됩니다.
- **방해 팝업 정리** — 화면 진입과 배정마다 흐름을 막던 확인창을 없앴습니다.
- **쉬운 말** — Cycle·Pool·Index 같은 용어를 `근무 묶음`·`별도 근무`·`패턴 시작 위치`처럼 쉬운 말로 바꿨습니다.

## 평일·휴일 시간 분리
- **평일/휴일 시간 따로 설정** — 근무 묶음마다 평일과 휴일(토·일·공휴일)의 근무시간·휴게를 따로 정할 수 있습니다. `[평일|휴일]` 탭으로 전환하며, 휴일 값을 비우면 평일과 동일하게 적용됩니다.
- **근무표·계산 반영** — 분리한 시간이 근무표 생성과 실적 계산에 그대로 반영됩니다. 기존 근무지는 평일 시간을 그대로 쓰던 방식이 유지됩니다(동작 불변).

## 계산 정확도 향상
- **공휴일 기본시간** — 공휴일에 직접 일한 시간은 전부 기본시간으로 처리합니다.
- **대체근무 중복 방지** — 대체근무는 대체표 기준으로 한 번만 반영해 중복 지급을 막고, 대체 취소 시 같은 이름의 다른 근무까지 잘못 풀리던 문제를 고쳤습니다.
- **수당 요율 기준** — 수당 요율을 가장 최근에 고친 값이 아니라 실제 근무한 날짜 기준으로 고릅니다.
- **저장 안전** — 승인과 수당 계산을 한 묶음(트랜잭션)으로 저장하고, JSON 복원 시 모든 표를 보존하며 복원 전 자료를 따로 남깁니다.

## 보안·성능·기타
- **로그인 보안** — 비밀번호를 여러 번 틀리면 잠시 잠그고, 기본 관리자 비밀번호를 화면에 보여주지 않으며, 최초 로그인 시 새 비밀번호로 바꾸도록 안내합니다.
- **사용성** — 어려운 안내 문구와 빈 화면을 쉬운 말로 정리하고, 고밀도 표 보기와 키보드(Esc·포커스) 사용성을 더했습니다.
- **속도** — 엑셀을 한 번만 읽도록 바꿔 실적 처리 속도를 높이고, 불필요한 지연을 제거했습니다.

## 안전성
- **이미 승인된 자료 불변** — 계산 로직 변경은 모두 forward-only로, 기존 승인완료본을 다시 바꾸거나 재승인 대상으로 표시하지 않습니다.
- **호환 마이그레이션** — 평일·휴일 분리 항목은 기존 자료와 호환되게 저장되어 업데이트 후에도 기존 근무지가 그대로 동작합니다. 안전을 위해 업데이트 전 데이터 백업을 권장합니다.
