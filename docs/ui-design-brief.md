## 레이아웃
- 좌측 고정 사이드바 + 우측 메인 콘텐츠 구조
- 상단에는 현재 메뉴 제목과 운영 컨텍스트를 표시
- 본문은 필터 카드, 요약 카드, 테이블, 차트, 액션 영역으로 구성

## 화면 원칙
- 대시보드: KPI 카드 8개 + 차트 2개 + 우선 확인 영역
- 인력 관리: 목록 테이블과 상세/이력 영역을 동시에 제공
- 근무지 관리: 1단계 패턴 등록, 2단계 조직 구성 흐름을 분리
- 근무표 배포: 월간 캘린더와 배포 경로, 배포 버튼을 같은 화면에 배치
- 실적 관리: 승인대기 그룹 목록과 계산 규칙을 같이 제공
- 수당 관리: 좌측 차트, 우측 상세 테이블, 하단 품의 신청 버튼 구성
- 운영 관리: 공휴일, 요율, 사용자, 양식 관리의 4개 하위 메뉴를 동일 톤으로 구성

## 금지
- 다크 모드 우선 설계 금지
- 과한 장식용 애니메이션 금지
- 영어 메뉴명 노출 금지
