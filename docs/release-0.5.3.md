# ShiftMgmt 0.5.3

조 관리·근무유형 도입 + 설정 적용 시작일 + 대체근무수당 제외 정책

이번 업데이트는 **근무지 조 구성을 직접 관리**할 수 있게 하고, **설정을 바꿔도 지나간 달의 계산이 흔들리지 않도록** 적용 시작일별로 저장합니다. 또한 **Pool·주간고정조의 대체근무수당을 제외**하는 정책과 **통상시급 소급 적용**을 추가했습니다. 이미 승인해 지급한 실적과 수당은 이번 업데이트로 바뀌지 않습니다.

## 조 관리와 근무유형
- **조 관리 화면 추가** — 근무지 등록 1단계 기본 설정에서 조 이름, 근무유형, 근무 묶음, 사용 여부, 순서를 직접 정합니다. 여기서 정한 순서 그대로 달력과 근무표에 나오고, 같은 이름을 두 번 쓰면 저장을 막습니다.
- **조별 근무유형 지정** — 조마다 `교대조 / 주간고정조 / Pool` 중 하나를 고릅니다. 수당 판정은 조 이름이 아니라 이 근무유형으로 하므로, 조 이름을 바꿔도 판정 결과는 달라지지 않습니다.
- **Pool 조도 근무표에 편성** — Pool 조에 사람을 배정하고 근무 묶음을 지정하면 다른 조와 똑같이 근무표가 만들어집니다. `배정 안 함`으로 두면 예전처럼 달력·근무표에서 빠집니다.
- **빠른 시작 패턴 3종 추가** — `주간고정 3주3휴`, `주야간 3주3휴3야3휴`, `주간고정 2조 + 주야교대 4조`를 고르면 조 수·근무유형·근무시간·조별 시작 위치가 한 번에 채워집니다.

## 근무지 설정의 적용 기간
- **적용 시작일로 저장** — 1단계에 적용 시작일 칸이 생겼습니다. 날짜를 그대로 두고 저장하면 **지금 설정을 수정**하고, 다른 날짜로 바꿔 저장하면 **그날부터 적용되는 설정이 하나 더** 생깁니다. 그 전 날짜의 근무 계산은 예전 설정 그대로입니다.
- **기간 이력 표시** — 지난 설정 / 오늘 적용 중 / 앞으로 적용될 설정을 기간과 함께 보여 줍니다. 종료일은 입력하지 않고 다음 설정 시작일의 전날로 자동 계산되어, 두 값이 어긋날 수 없습니다.
- **달 단위 적용** — 어떤 달의 근무표는 그 달 1일에 유효한 설정으로 만들어집니다. 이미 저장된 근무표는 자기가 만들어질 때 쓴 설정을 그대로 기억합니다.

## 대체근무수당 제외 정책
- **근무유형으로 판정** — Pool 인원이 교대조 근무를 대신하면 예전처럼 지급하지 않고, **주간고정조 인원이 대신한 경우도 같은 기준으로 제외**합니다. 야간·연장 몫을 포함해 전액 제외됩니다.
- **사유 표시** — 실적 화면의 인력 정보 창에서 대체근무자 근무유형, 대체 대상 근무유형, 지급 여부와 사유를 한국어로 확인할 수 있습니다.
- **적용 시작일** — 운영 관리에서 적용 시작일을 정하면 **그 날짜 이후 근무부터만** 새 제외 규칙이 적용됩니다. 비워 두면 새 규칙을 적용하지 않습니다. Pool 제외는 예전 규칙이라 날짜와 무관합니다.
- **대기 실적 자동 재판정** — 적용 시작일을 나중에 설정해도, 이미 승인 대기 중인 회수 근무표를 다음 실적 화면 조회에서 새 기준으로 다시 판정합니다. 승인이 끝난 보관본은 다시 읽지 않습니다.

## 통상시급
- **지난 날짜로도 적용** — 예전에는 지금 적용 중인 시급 시작일보다 뒤 날짜만 넣을 수 있어 소급 인상과 잘못 넣은 날짜 정정이 막혔습니다. 이제 지난 날짜도 넣을 수 있고, **같은 날짜면 그 시급을 고쳐 씁니다.**
- **기간 겹침 방지** — 새 시급을 넣으면 앞 줄은 전날로 끊기고, 새 줄은 다음 줄 시작일의 전날까지로 자동 정리됩니다.
- **승인분 보호 안내** — 지난 날짜를 고르면 확인 창이 먼저 뜹니다. 아직 승인하지 않은 실적은 새 시급으로 다시 계산되고, **이미 승인해 지급한 실적과 수당은 그대로 유지**됩니다. 엑셀 시급 일괄 업데이트도 같은 규칙입니다.

## 화면 정리
- **근무표 화면 중복 카드 제거** — Pool 조를 근무 묶음에 배정했을 때 조 카드와 빈 Pool 카드가 겹쳐 보이던 것을 정리했습니다.
- **조 관리 글자 잘림 수정** — 근무유형 칸에서 `주간고정조`가 잘려 보이던 것을 고쳤습니다.

## 안전성
- **과거 지급분 불변** — 새 제외 규칙과 소급 시급 모두 이미 승인·계산된 실적과 수당을 다시 계산하지 않습니다.
- **DB 구조 변경 포함** — 조별 설정과 설정 적용 시작일을 저장하기 위해 데이터베이스에 표와 칸이 추가됩니다. 업데이트 시 자동으로 반영되지만, 적용 전에 **DB 백업**을 한 번 받아 두시길 권합니다.
