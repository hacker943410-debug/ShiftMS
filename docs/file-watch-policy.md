# 파일 감시 정책 초안

작성일: 2026-03-11

이 문서는 승인대기/승인완료 폴더 감시 정책의 1차 초안이다. 목적은 파일 감시 서비스가 어떤 경로를 감시하고, 어떤 이벤트를 기록하며, 어떤 기준으로 중복 파일을 식별할지 먼저 고정하는 데 있다.

## 1. 감시 대상

1. `WATCH_PENDING_DIR`
   승인 대기 실적 파일 유입 폴더
2. `WATCH_APPROVED_DIR`
   승인 완료 후 이동 또는 보관 폴더

## 2. 이벤트 정책

감시 서비스는 아래 이벤트만 우선 다룬다.

1. `file-added`
   새 파일이 감지된 경우
2. `file-changed`
   기존 파일이 수정된 경우
3. `file-removed`
   파일이 제거된 경우
4. `watcher-error`
   감시 중 오류가 발생한 경우

## 3. 중복 식별 키

1. 1차 키는 `normalized_path + size + last_modified_ms`
2. 이후 실제 승인 저장 단계에서 checksum을 추가할 수 있다.
3. 같은 중복 키가 다시 들어오면 UI에서는 중복 후보로 표시하고, 자동 승인 처리하지 않는다.

## 4. 초기 프로토타입 범위

이번 단계는 아래까지만 구현한다.

1. 설정 경로 기준 감시 대상 경로 해석
2. watcher 상태 모델 생성
3. 파일 이벤트를 직렬화 가능한 메타데이터로 변환
4. 중복 식별 키 생성

실제 background watcher 등록과 renderer 실시간 반영은 후속 작업이다.

## 5. 후속 작업

1. 실제 `chokidar` watcher lifecycle 연결
2. renderer 진단 화면에 감시 상태 표시
3. 감지 파일 목록과 승인 큐 연결
4. checksum 기반 중복 감지 확장
