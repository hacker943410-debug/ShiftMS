# ShiftMgmt 0.4.23

교대 근무표 복구 시 근무시간 누락 수정 (휴일·대체 실적 0분 방지)

근무 패턴이 비표준 근무코드(A/B/C 등)를 쓰는 근무지에서 근무표 복구 시 주간/야간 근무시간이 비어 휴일·대체 실적이 0분(수당 0원)으로 계산되던 문제를 수정했습니다.

## 실적 계산
- **근무 시간대 인식** — 근무표 복구 시 근무 패턴의 시작 시각으로 주간(D)/석간(E)/야간(N)을 분류해, 근무표의 주간·야간 칸에 실제 근무시간을 채웁니다. 패턴이 `A/B/C` 등 표준 D/E/N과 다른 근무코드를 써도 근무시간이 비지 않습니다.
- **기존 근무지 보존** — 이미 주간/야간(D/N) 코드를 쓰던 근무지는 기존 근무시간을 그대로 유지하고 덮어쓰지 않습니다(회귀 없음).

## 배경
- 그동안 근무표 칸은 주간/야간 위치(D/E/N)로 읽으면서, 근무시간은 패턴의 근무코드로만 찾았습니다. 패턴이 `A/B/C`(예: 5조3교대 A=08:00–17:00, C=18:00–08:00)를 쓰는 근무지는 D/E/N 시간을 찾지 못해 복구된 근무표에 시간이 비었고, 그 결과 법정공휴일/대체 근로시간이 0분 → 수당 0원으로 계산됐습니다.
- 단, 해당 월의 근무표가 시스템에 존재해야 정상 계산됩니다(배포 근무표 원본이 없어 복구할 수 없는 달은 별도 사안).
