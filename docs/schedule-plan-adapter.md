# 근무표 생성기 어댑터 초안

작성일: 2026-03-11

이 문서는 `배포_근무표샘플.xlsx`를 기준으로 한 근무표 생성기 어댑터 초안이다. 목적은 캘린더형 근무표 템플릿에 월별 근무 데이터를 어떤 규칙으로 매핑할지 먼저 고정하는 데 있다.

## 1. 템플릿 구조 요약

샘플 파일 `배포_근무표샘플.xlsx`의 첫 시트는 `교대 근무 계획표`다.

확인된 주요 앵커:

1. 근무지명 표시 영역
   - 예시: `C3`에 `보라매DC`
2. 날짜 헤더 라인
   - `B9`는 `DATE`
   - 실제 날짜는 `C9`, `F9`, `I9`처럼 3칸 간격으로 반복
3. 교대 행
   - `B10`: `Day Shift`
   - `B11`: `Evening Shift`
   - `B12`: `Night Shift`
   - `B13`: `DAY OFF`

## 2. 1차 매핑 규칙

1. 날짜 열은 시작 열 `C`부터 3칸 간격으로 확장된다.
2. 각 날짜 열의 첫 칸에 교대 코드가 들어간다.
3. 교대 행 매핑:
   - `D` -> `Day Shift`
   - `E` -> `Evening Shift`
   - `N` -> `Night Shift`
   - `O`, `OFF`, `X` -> `DAY OFF`
4. 사이트명은 `siteNameCell`에 기록한다.

## 3. 프로토타입 범위

이번 단계 어댑터는 아래까지만 다룬다.

1. 샘플 템플릿의 날짜 열 배치 구조 식별
2. 교대 코드별 대상 행 식별
3. 월간 근무 데이터에서 셀 업데이트 목록 생성

실제 xlsx 파일 쓰기와 merged cell 보존은 후속 작업이다.

## 4. 후속 작업

2. 인원별/조별/사이트별 출력 포맷 확정
