# 반올림 및 절삭 정책

작성일: 2026-03-11

이 문서는 ShiftMgmt_V3.4의 계산 반올림 및 절삭 정책을 확정한다. 목적은 계산 결과가 화면, 테스트, 승인 스냅샷에서 모두 동일하게 재현되도록 하는 데 있다.

## 1. 정책 요약

1. 시간 계산은 분 단위 정수로 유지한다.
2. 금액 계산은 원 단위 정수로 저장한다.
3. 수당 금액 계산 시 소수점은 `round-half-up`으로 처리한다.
4. 개별 수당 항목 금액을 먼저 반올림한 뒤 총액을 합산한다.
5. UI 포맷은 반올림 완료 후의 정수 금액에만 적용한다.

## 2. 적용 규칙

### 시간

- 시작 시각과 종료 시각은 분으로 변환한다.
- 자정 넘김은 분 계산 단계에서 처리한다.
- 휴게시간 차감 후에도 결과는 분 단위 정수다.

### 금액

- 공식: `시급 x (근로분 / 60) x 배수`
- 계산 결과가 소수점이면 `Math.round`와 동일한 `round-half-up`을 적용한다.
- 총 지급액은 반올림 완료된 각 항목 금액의 합계다.

## 3. 예시

1. `10000 x (30 / 60) x 1.5 = 7500`
   결과: `7500`
2. `10000 x (25 / 60) x 1.5 = 6250`
   결과: `6250`
3. `10000 x (1 / 60) x 1.5 = 250`
   결과: `250`
4. `10000 x (1 / 60) x 1.3333 = 222.216...`
   결과: `222`

## 4. 후속 검토 항목

1. 세법 또는 사내 규정에 따라 항목별 절사가 필요한 경우 버전 정책으로 분리할지 검토
2. 야간/휴일 중첩 수당의 계산 순서를 별도 정책으로 둘지 검토
