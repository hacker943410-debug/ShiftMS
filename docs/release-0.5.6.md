# ShiftMgmt 0.5.6

0.5.5 게시 뒤 교차검증에서 찾은 결함 23건 수정

0.5.5는 평소 거치던 **교차검증 없이 나갔습니다.** 게시 직후 다시 검증한 결과 결함 16건이 확인됐고, 그 수정들을 다시 뒤집어 보는 과정에서 4건, 이후 두 차례 재검증에서 3건이 더 나와 **모두 23건을 이번에 고쳤습니다.** 새 기능은 없고, 전부 잘못 동작하던 것을 바로잡은 수정입니다. **이미 승인해 지급한 과거 실적과 수당은 이번 업데이트로 바뀌지 않습니다.**

## 금액과 지급 판정이 틀리던 것
- **승인 사이에 엑셀을 고치면 옛 금액으로 굳던 문제** — 재승인 파일을 끝내는 길이 확정 단추·수당 근무지 승인·자동 보관 **세 가지**인데, 시간만 보고 완료 처리하던 곳이 있었습니다. 두 번의 승인 사이에 원본 엑셀이 바뀌면 **바뀌기 전 금액으로 굳었습니다.** 이제 세 길 모두 승인 당시와 같은 내용인지 확인합니다.
- **대기조로 옮기면 과거 대체근무가 지급 불가가 되던 문제** — 대기조 여부를 사람 단위로 한 번만 판정해서, 누군가를 대기조로 옮기면 **그 사람의 지난 대체근무가 전부 지급 대상에서 빠지고 되돌릴 방법이 없었습니다.** 이제 근무한 날에 어느 조에 있었는지로 판정합니다.
- **승인 뒤 생긴 오류가 있는데도 확정되던 문제** — 승인한 뒤에 고용 기간 밖 근무 같은 오류가 생긴 줄이 그대로 확정되는 경우가 있었습니다. 이제 막히고, **화면도 같은 기준으로 판정**해 "화면은 완료인데 저장은 거부" 되는 어긋남이 없습니다. 고쳐야 할 오류가 그 줄에 보이도록 했습니다.
- **복원·가져오기가 적용 시작일을 지우던 문제** — 데이터베이스를 복원하거나 Access 자료를 가져오면 근무 설정의 **적용 시작일이 사라져 대체수당을 누가 받는지가 조용히 바뀌었습니다.** 이제 그대로 남습니다.

## 이유 없이 승인이 뒤집히던 것
- **조 이름·순서만 바꿔도 재검토로 돌아가던 문제** — 정렬 순서, 조 이름, 사람 이름, 사번, 대기조 표시처럼 **화면에만 쓰이는 항목이 비교 대상에 들어 있어서**, 조 이름을 바꾸거나 조원 순서를 바꾸면 이미 승인한 휴일 실적이 재검토로 돌아갔습니다. 이제 비교할 때 이런 항목은 빼고 봅니다. 이미 굳은 승인은 이 수정으로 움직이지 않습니다.
- **시급에서 나온 알림이 승인을 흔들던 문제** — 시급 때문에 생긴 알림이 예전 방식 비교에 섞여 들어갔습니다. 이제 이유 표시를 붙여 비교에서 제외합니다. **지금 쓰시는 승인 자료 257건이 전부 예전 방식으로 비교되므로, 이번 묶음에서 가장 체감이 큰 수정입니다.**

## 저장이 도중에 끊길 때
- **반쪽만 저장되던 곳 묶기** — 시급 한 줄 저장과 종료, 근무 패턴, 앱 설정과 다시 읽기 표시, 실적 항목 저장이 여러 번에 나눠 기록되어 중간에 끊기면 반쪽만 남을 수 있었습니다. 이제 각각 **한 덩어리로 묶어** 저장합니다.
- **시작할 때 하는 연장근무 보정** — 프로그램을 켤 때 도는 보정이 승인된 수당 줄을 나눠 고쳐 썼고, **여기서 실패하면 프로그램 시작 자체가 멈췄습니다.** 이제 한 덩어리로 처리하고, 이 보정이 실패해도 프로그램은 정상적으로 켜집니다.

## 다시 읽기와 분석 결과 보관
- **못 읽은 파일을 읽은 것으로 표시하던 문제** — 저장에 실패했거나 파일을 아예 열지 못했는데도 '다시 읽음'으로 표시되어, 그 파일이 **옛 시급과 옛 근무표로 계산한 줄을 계속 보여 줬습니다.** 이제 실제로 읽어 저장까지 성공했을 때만 표시가 지워집니다.
- **일시적 읽기 실패가 멀쩡한 분석을 지우던 문제** — 파일을 잠깐 못 읽었을 뿐인데 저장돼 있던 분석 결과가 빈 오류 줄로 덮여, 달 정보와 운영자가 정한 내용까지 사라졌습니다. 이제 읽기에 실패하면 **기존 결과를 그대로 둡니다.**
- **달을 골라 조회할 때 남의 폴더 결과를 지우던 문제** — 예를 들어 `2026_4_근무지.xlsx` 파일이 **3월 폴더에** 들어가 있으면, 4월을 조회할 때 그 파일의 분석 결과가 지워졌습니다. 파일은 그대로 있는데 화면에서만 사라졌습니다. 이제 조회와 정리가 **완전히 같은 범위**를 봅니다.
- **보관본 덮어쓰기와 직급 변경** — 승인 보관본을 강제로 새로 읽으면 덮어쓰기 방지가 꺼지던 것을 고쳤습니다. 직급을 바꿔도 다시 읽기 표시가 남지 않아 **옛 직급이 승인과 별첨 1에 그대로 나가던 것**도 고쳤습니다.

## 그 밖의 수정
- **안내 문구가 엉뚱한 창까지 따라가던 문제** — 근무유형을 바꿀 때 뜨는 안내가 관계없는 다른 완료 창에까지 남아 있던 것을 고쳤습니다.
- **새 근무 패턴 비교 기준** — 근무 패턴을 새로 만들 때 지금 실제로 쓰이는 판이 아니라 다른 판과 비교하던 것을 고쳤습니다.

## 안전성
- **과거 지급분 불변** — 이미 굳은 승인의 보관된 근거는 이번 수정으로 다시 쓰이지 않습니다. 비교 방식만 바뀌므로 이미 지급이 끝난 줄이 움직이지 않습니다.
- **DB 구조 변경 없음** — 이번 업데이트는 데이터베이스 표·칸을 추가하지 않습니다.

## 아직 남은 것 (다음 묶음)
아래는 **고치는 것 자체가 이미 승인된 실적을 뒤집기 때문에** 이번에 일부러 미룬 항목입니다.
- **근무지 이름이나 고용형태를 바꾸면**, 예전에 승인한 실적은 여전히 재검토로 뒤집힙니다.
- **인력 관리 화면에서 조를 바꾸면** 과거 배정까지 함께 덮어써서, 위의 대기조 수정이 그 경우에는 작동하지 않습니다. 조 변경은 되도록 근무 설정 화면에서 하시기를 권합니다.
- **대기조에서 지급 대상으로 바뀐 사람**에게 시급이 등록돼 있지 않으면 오류로 승인이 막힙니다. 시급을 등록하면 풀립니다.
