# 샘플 Excel 구조 분석

작성일: 2026-03-11

이 문서는 `양식샘플` 폴더에 있는 Excel 파일 구조를 분석한 결과다. 목표는 템플릿 식별 규칙과 파서 프로토타입의 기준을 먼저 고정하는 데 있다.

## 1. 샘플 파일 목록

1. `배포_근무표샘플.xlsx`
2. `별첨1_샘플.xlsx`
3. `별첨2_샘플.xlsx`
4. `품위서_샘플.xlsx`

## 2. 파일별 구조 요약

### `배포_근무표샘플.xlsx`

- 시트명: `교대 근무 계획표`
- 성격: 월간 교대 근무 계획표
- 구조 특징:
  - 상단 설명 영역이 크고 merged cell 비중이 높다.
  - 날짜 헤더가 가로 방향으로 확장되는 캘린더형 구조다.
  - `Day Shift`, `Evening Shift`, `Night Shift`, `DAY OFF` 같은 패턴 행이 존재한다.
- 파싱 관점:
  - 일반적인 행 단위 테이블 파서보다 캘린더형 어댑터가 필요하다.

### `별첨1_샘플.xlsx`

- 시트명: `별첨1`
- 성격: 시간외근로 상세 내역
- 구조 특징:
  - 1~4행은 제목 및 다단 헤더다.
  - 실데이터는 5행부터 시작한다.
  - 컬럼 예시:
    - `No.`
    - `사번`
    - `성명`
    - `직급`
    - `단위 조직`
    - `구분`
    - `근무 날짜`
    - `근무 시간`
    - `기본 근로수당`
    - `요율`
- 파싱 관점:
  - 행 기반 파싱이 가능하다.
  - 날짜와 숫자 셀이 섞여 있어 셀 타입 정규화가 필요하다.

### `별첨2_샘플.xlsx`

- 시트명: `별첨2`
- 성격: 월간 지급 현황 집계표
- 구조 특징:
  - 상단 제목과 기간 표기가 있다.
  - 3~4행에 2단 헤더가 존재한다.
  - 실데이터는 5행부터 시작한다.
  - 컬럼 예시:
    - `구성 조직`
    - `이름`
    - `대체근무`
    - `연장근무`
    - `법정공휴일 근무`
    - `합계`
  - 중간에 `소계` 행이 삽입된다.
- 파싱 관점:
  - 행 기반 파싱이 가능하지만 소계/합계 행 제외 규칙이 필요하다.

### `품위서_샘플.xlsx`

- 시트명: `품의서`
- 성격: 승인 문서
- 구조 특징:
  - 본문 중심 문서형 배치다.
  - `문서번호`, `작성부서`, `작성자`, `제목`, `배경 및 근거` 등의 레이블이 분산되어 있다.
  - 일반 표 구조보다 위치 기반 텍스트 추출 성격이 강하다.
- 파싱 관점:
  - 데이터 입력 파서보다는 문서 생성기 템플릿으로 보는 것이 맞다.

## 3. 1차 템플릿 식별 규칙

1. 첫 번째 시트명이 `교대 근무 계획표`이면 `schedule-plan`
2. 첫 번째 시트명이 `별첨1`이면 `attachment1`
3. 첫 번째 시트명이 `별첨2`이면 `attachment2`
4. 첫 번째 시트명이 `품의서`이면 `proposal`
5. 그 외는 `unknown`

## 4. 프로토타입 범위

이번 단계 파서 프로토타입은 아래까지만 다룬다.

1. 워크북의 첫 시트를 기준으로 템플릿 종류 식별
2. `별첨1`, `별첨2`의 첫 번째 데이터 행 추출
3. 문서형/캘린더형 파일은 메타데이터 수준까지만 식별

## 5. 후속 작업

1. 실적 회신 원본 양식 확보 후 별도 `performance` 템플릿 식별 규칙 추가
2. `배포_근무표샘플.xlsx`용 캘린더형 어댑터 설계
3. `품위서_샘플.xlsx`용 위치 기반 생성기 설계
4. 소계/합계 행 제외 정책과 수식 셀 처리 정책 확정
