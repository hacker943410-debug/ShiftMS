# 근무 패턴 기준정보 정책

작성일: 2026-03-11

## 목적

`shift_patterns`는 근무표 생성과 월간 배정 기준에 직접 연결되는 기준정보다.
이미 운영에 사용한 패턴은 삭제하지 않고 상태 전환으로만 관리한다.

## 원칙

1. 패턴 삭제 금지
2. 사용 중단은 `inactive` 전환으로 처리
3. step 정의는 비활성화 이후에도 보존
4. 다시 써야 하면 새 패턴을 만들거나 비활성 패턴을 명시적으로 수정

## UI 정책

- 목록에서는 활성 패턴에만 `비활성화` 액션을 노출한다.
- 비활성 패턴은 조회 대상에는 남기되 운영 선택에서는 제외할 수 있다.
- 조용한 삭제 버튼은 제공하지 않는다.
