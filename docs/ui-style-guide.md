# UI 스타일 가이드

## 컬러
- 앱 배경: `#F8F9FB`
- 카드 배경: `#FFFFFF`
- 액센트: `#3E56B6`
- 액센트 배경: `#EBF0FF`
- 본문 텍스트: `#1D2F3A`
- 보조 텍스트: `#6C798F`
- 경계선: `#D1D9F0`
- 성공: `#059669`
- 경고: `#D97706`
- 위험: `#DC2626`

## 타이포그래피
- 기본 서체: Pretendard
- 숫자 강조: Inter 또는 숫자 가독성이 높은 산세리프
- 메뉴/버튼/테이블 텍스트는 과도한 장식 없이 명료하게 유지

## 컴포넌트 규칙
- 카드 라운드: 14px ~ 20px
- 주요 버튼: 파란색 배경 + 흰색 텍스트
- 보조 버튼: 흰색 배경 + 경계선
- 상태 표기: 색상만 쓰지 말고 배지 텍스트를 함께 사용
- 테이블 행 높이: 여유 있게 유지하고 hover 배경을 제공

## 인터랙션
- hover는 1px 정도의 가벼운 상승 효과만 사용
- 중요 액션 버튼은 같은 위치에서 일관되게 배치
- 필터는 화면 상단 첫 카드에 배치

## 반응형
- 1280px 이하에서는 2열 레이아웃을 1열로 전환
- 모바일에서도 텍스트와 카드 간격이 깨지지 않도록 유지
