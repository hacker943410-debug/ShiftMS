# ShiftMgmt 0.4.24

근무표 복구 안정화 (비정상 근무시간 차단·부분 복구 자가 치유)

0.4.23(근무표 복구 시 근무코드 A/B/C↔근무표 칸 D/E/N 매핑 수정)에 이어, 복구 동작을 더 견고하게 다듬었습니다. 비정상 근무시간을 차단하고, 시간을 못 찾은 칸은 조용한 0분 대신 경고로 알리며, 부분만 복구된 달과 옛 버전이 남긴 미완성 근무표를 자동으로 다시 채웁니다.

## 근무표 복구
- **비정상 근무시간 차단** — 시작과 종료가 같은 0길이 근무시간을 복구에서 제외해, 약 24시간짜리 유령 근무로 계산되지 않습니다. 자정 경계 분류(16:00–00:00=석간, 00:00–08:00=야간)도 함께 보정했습니다.
- **미해결 칸 경고** — 근무 패턴에서 시간을 찾지 못한 칸은 0분 행으로 저장하지 않고 건너뛴 뒤 “근무 시간을 확인하지 못해 제외했습니다” 경고를 표시합니다. 조용한 0분 대신 원인이 드러납니다.
- **부분·미완성 복구 자가 치유** — 일부만 복구된 달과 옛 버전이 남긴 미완성 근무표(빈 시간·0건·중복 행)를 다시 복구 대상으로 삼아 기존 행을 교체하며 채웁니다. 결과가 같으면 다시 저장하지 않아 매 실행 시 불필요한 재처리를 막습니다.
- **수동 근무표 보존** — 운영자가 직접 만든 근무표와 이미 정상인 근무지의 근무시간은 자동 복구가 절대 덮어쓰지 않습니다.

## 배경
- 0.4.23이 근무코드(A/B/C)를 근무표 칸(D/E/N)에 시간으로 매핑하도록 고친 뒤, 그 위에서 발생할 수 있는 경계 상황(0길이 근무시간, 시간 미해결 칸, 부분 복구·옛 미완성 데이터, 매 부팅 재처리)을 추가로 단단히 했습니다.
- 단, 해당 월의 근무표 원본(배포 근무표 파일)이 없으면 복구할 게 없어 여전히 실적이 0입니다(별도 사안).
