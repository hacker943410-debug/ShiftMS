# ShiftMgmt v0.4.17

## 상태
- 현재 작업 브랜치: `release/0.4.17`
- 대상 버전: `0.4.17`
- 현재 단계: 승인된 복구형 패치 적용 및 배포 검증
- 기준 산출물:
  - `artifacts/releases/v0.4.17/RESULT_REPORT.md`
  - `artifacts/releases/v0.4.17/RELEASE_MANIFEST.json`
  - `artifacts/releases/v0.4.17/QA_CHECKLIST.md`

## 요약
0.4.17은 Git에 보존된 0.4.14 소스 기준에서 0.4.15와 0.4.16의 승인된 안정화 항목을 재구현한 복구형 패치입니다. 업데이트 알림, 패치노트 표시, 수당 계산 기준, 승인 재조회, Excel 재출력, DB 복구, 월 근무표 저장 보호, 요율 검증, 근무표 규칙 경고를 보강했습니다.

## 변경 사항
- 프로그램 시작 시 새 버전이 있으면 다운로드 전에 업데이트 모달과 패치노트를 먼저 표시합니다.
- 업데이트 다운로드는 사용자가 `다운로드` 버튼을 누른 뒤에만 시작됩니다.
- 패치노트는 기능, 사용자 영향, 검증 기준을 표로 확인할 수 있도록 개선했습니다.
- 수당 금액은 기본/연장/야간 항목별 올림 합산이 아니라 원시 금액 합산 후 최종 1회 올림으로 계산합니다.
- 요율 영향 미리보기도 실제 수당 계산과 같은 1회 올림 기준을 사용합니다.
- 승인 완료 파일을 승인 대기 폴더로 되돌려 부분 승인 상태를 재조회하는 흐름을 검증했습니다.
- 품의 승인 후 품의서, 별첨1, 별첨2 Excel 출력 흐름을 검증했습니다.
- 품의서/별첨 Excel 출력과 양식 스타일 적용 시 병합 셀 충돌을 방지합니다.
- 화면 오류가 앱 전체 white-screen으로 확산되지 않도록 공통 오류 경계를 추가했습니다.
- 월 근무표 저장은 직원 사번 검증 후 트랜잭션으로 처리해 실패 시 기존 데이터를 유지합니다.
- DB 시작 시 최신 migration backup만 남은 상황을 자동 복구합니다.
- 운영 요율 매트릭스는 빈 값과 비정상 숫자를 저장하지 않습니다.
- 요율 저장 전 영향 미리보기와 지급 대상 수당 0원화 경고를 제공합니다.
- 근무지 패턴 산출, 근무패턴 반복 해석, 인력관리 집계 회귀를 보강했습니다.
- 운영 설정의 근무표 경고 기준 저장과 근무표 화면 규칙 경고를 추가했습니다.

## 제외
- 인증 bootstrap 정책 변경은 이번 패치에 포함하지 않았습니다.
- Electron navigation/window-open/CSP 제한은 이번 패치에 포함하지 않았습니다.
- 월마감/급여 잠금은 별도 패치 대상으로 남겨뒀습니다.
