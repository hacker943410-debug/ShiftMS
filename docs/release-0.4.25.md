# ShiftMgmt 0.4.25

실적관리 계산·표시 안정화

이번 업데이트는 실적관리 새로고침과 근무시간 표시 기준을 바로잡은 패치입니다. 근무표에서 `None`으로 지정한 칸은 실적 대상에서 제외되며, 구형 품의서 템플릿 등록도 사전에 차단합니다.

## 근무시간 계산
- **Cycle 근무시간 표시 순서** — 근무 패턴이 `A, C, B`처럼 저장되어 있어도 근무지 상세 보기에서는 canonical slot 기준으로 `1근`, `2근`, `3근` 순서에 맞춰 표시합니다.
- **새로고침 재계산** — 실적관리 새로고침은 변경 없는 반환 파일도 다시 파싱해 저장된 월근무표 시간이 바뀐 경우 총근무/연장 시간 계산 결과를 갱신합니다.
- **배포 후 승인대기 계산 검증** — 월간 근무표 생성 경로는 기존 slot 기반 계산을 유지하며, 혼합 duty code 근무시간 보존 테스트로 회귀를 확인했습니다.

## 실적 대상 제외
- **None 제외** — 근무표 또는 반환 근무표에서 `None`으로 지정한 법정휴일, 대체, 연장 슬롯은 실적관리 목록과 승인 대상에서 제외됩니다.
- **빈칸과 구분** — `None`은 단순 빈칸이 아니라 운영자가 실적 제외를 명시한 값으로 해석합니다.

## 실적관리 화면
- **필터 순서** — 필터는 `연도`, `월`, `근무지명`, `조회구분`, `근로유형` 순서로 표시합니다.
- **기존 필터 폭 유지** — 필터 박스 너비는 기존 값과 동일하게 유지하고 순서만 바꿨습니다.
- **표 밀도 조정** — 실적 현황 표의 여백과 배지를 조밀하게 조정해 데스크톱 화면에서 불필요한 좌우 스크롤을 줄였습니다. 좁은 화면에서는 가로 스크롤 fallback을 유지합니다.

## 양식 관리
- **구형 품의서 템플릿 차단** — 품의서 템플릿 등록 시 신형/구형 배치를 판정하고, 구형 배치로 확인되면 저장을 막아 문서 생성 단계의 병합 오류를 예방합니다.
