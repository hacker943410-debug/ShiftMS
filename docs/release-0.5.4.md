# ShiftMgmt 0.5.4

별첨1 직급 표시 복구 + 시급 적용일·조원 순서 수정 + 변경후 근무자 인정

이번 업데이트는 **별첨1에서 직급이 `-`로만 나오던 문제**, **시급 일괄 적용일이 오늘 날짜로 저장되던 문제**, **배포 엑셀의 조원 순서가 이름순으로 바뀌던 문제**를 바로잡고, **2026년 7월 1일 근무부터 변경후 칸의 근무자를 실제 근무자로 인정**합니다. 이미 승인해 지급한 과거 실적과 수당은 이번 업데이트로 바뀌지 않습니다.

## 별첨1 직급 표시
- **사번 대조 보강** — 인력 정보의 사번 앞뒤에 보이지 않는 공백이 있어도 맞춰 보고, 삭제 처리된 인력도 과거 문서에는 직급을 찍습니다. 사번으로 못 찾으면 **이름으로 한 번 더** 찾되, 같은 이름이 둘 이상이면 다른 사람 직급을 빌려 쓰지 않도록 아예 쓰지 않습니다.
- **PDF에도 직급 칸 추가** — PDF 별첨1에는 직급 칸 자체가 없어 데이터와 무관하게 직급이 빠졌습니다. 성명 옆에 직급 칸을 추가해 엑셀 출력과 같게 맞췄습니다.
- **못 찾은 인원 안내** — 그래도 직급을 못 찾은 인원은 **출력 완료 안내에 이름을 보여 줍니다.** 인력 관리에서 직급을 채운 뒤 다시 출력하면 됩니다. 직급은 표시 전용이라 금액과 승인 상태에는 영향이 없습니다.

## 통상시급 일괄 적용일
- **날짜 클릭 즉시 확정** — 예전에는 날짜를 누른 뒤 확인 단추까지 눌러야 확정됐고, 그 전에 화면 다른 곳을 누르면 선택이 조용히 풀려 기본값인 **오늘**로 저장됐습니다. 이제 날짜를 누르는 순간 바로 확정됩니다. 월 선택 달력도 같습니다.
- **오늘 날짜 계산 통일** — 새벽 시간대에 세계 표준시 차이로 하루 전 날짜가 기본값으로 들어가던 것을 고치고, 인력·근무지·활동이력·수당·운영요율 화면의 오늘 기본값 계산을 하나로 통일했습니다.
- **적용일 눈으로 확인** — 일괄 적용 완료 안내와 성공 문구에 적용일을 함께 보여 주어, 의도한 날짜로 들어갔는지 바로 확인할 수 있습니다.

## 배포 엑셀 조원 순서
- **배치 순서 그대로 출력** — 배포 엑셀을 만들 때 이름 가나다순으로 다시 정렬해 조 구성 화면과 다른 순서로 나가던 것을 고쳤습니다. 이제 **조 순서 → 조 안 배치 순서 → 사번** 순서로 나가, 조 구성 맨 위 인원이 엑셀에서도 맨 위에 옵니다.

## 변경후 근무자 인정
- **변경후 우선 규칙** — 변경전 칸에 누가 적혀 있든 **변경후 칸의 사람을 실제 근무자로 인정**해 법정휴일수당을 계산합니다. **2026년 7월 1일 근무부터** 적용되며, 그 전 근무는 예전 규칙 그대로라 과거 계산과 지급분이 바뀌지 않습니다.
- **적용 시작일 변경 가능** — 운영 관리에서 적용 시작일을 바꿀 수 있습니다.
- **빠지는 근무 구멍 봉합** — 협력사 표기(`BP(...)`)나 빈칸 표식이 변경전 칸에 있어도 변경후 근무자가 조용히 빠지는 일이 없어졌습니다. 경고 문구도 무엇을 하면 되는지 알려 주는 말로 바꿨습니다.
