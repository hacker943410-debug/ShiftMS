# 인력 이력 정책

작성일: 2026-03-11

## 목적

`wage_rates`와 `employee_site_assignments`는 감사 추적 대상이다.  
운영 중 잘못 입력된 이력을 조용히 덮어쓰거나 삭제하지 않고, 항상 이력 행을 남기는 방향으로 관리한다.

## 원칙

1. 삭제 금지
2. 수정 대신 새 이력 추가
3. 활성 이력은 종료 처리만 허용
4. 종료일은 시작일보다 이를 수 없음
5. 동일 직원에 대해 활성 시급/활성 배정은 각 1건만 유지

## 시급 이력 규칙

- 새 시급 추가 시 기존 `effective_to IS NULL` 행은 새 `effective_from` 날짜로 종료한다.
- 기존 행을 직접 수정하지 않는다.
- 활성 시급을 중단해야 할 경우 `effective_to`만 채워 종료한다.

## 배정 이력 규칙

- 새 배정 추가 시 기존 `status = 'active'` 행은 `ended`로 종료한다.
- 종료 처리 시 `end_date`를 기록한다.
- 종료된 배정 행은 다시 활성화하지 않는다. 필요한 경우 새 배정 행을 추가한다.

## UI 정책

- 화면에서는 삭제 버튼을 두지 않는다.
- 활성 행에만 `종료` 액션을 노출한다.
- 종료 후에는 목록과 현재 상태를 즉시 다시 조회한다.
