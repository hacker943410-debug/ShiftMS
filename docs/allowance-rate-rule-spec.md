# 수당 요율/계산 규칙

## 기준 행

수당 요율은 단일 코드 배율이 아니라 `근로유형 5행 x 기본/연장/야간 3열` 구조로 관리한다.

| 근로유형 | 기본근로수당요율 | 연장근로수당요율 | 야간근로수당요율 |
| --- | --- | --- | --- |
| 법정공휴일 | 1.5 | 1.5 | 1.5 |
| 평_대체근로수당 | 1.5 | 2.0 | 2.5 |
| 휴_대체근로수당 | 1.5 | 2.0 | 2.5 |
| 평_연장근로수당 | 0 | 1.5 | 2.0 |
| 휴_연장근로수당 | 0 | 0 | 0 |

## 계산 축

- 야간근로시간: 22:00 ~ 06:00 구간에서 산출하며, 휴게시간은 야간시간에서 우선 차감한다.
- 기본근로시간: 야간 차감 후 남은 비야간 근로시간 중 최대 8시간 한도까지 배정한다.
- 연장근로시간: 기본근로시간 8시간을 채우고 남은 비야간 근로시간

엔진은 `기본/연장/야간` 시간을 서로 중복 없이 분해한다. 따라서 `기본근로시간 + 연장근로시간 + 야간근로시간 = 총근로시간`이 되도록 유지한다.

## 근로유형 매핑

- `법정공휴일`, `공휴일`, `휴일근로` 계열: `법정공휴일`
- `평_대체`, `대체근로` 계열: `평_대체근로수당`
- `휴_대체` 계열: `휴_대체근로수당`
- `평_연장`, `연장근로` 계열: `평_연장근로수당`
- `휴_연장` 계열: `휴_연장근로수당`

`휴일근로`처럼 휴일 키워드가 있지만 명시 코드가 없는 경우는 우선 `법정공휴일`로 본다. 샘플 실적 파일이 이 값을 사용하기 때문이다.

## 출력/집계 규칙

- 품의/별첨 요약은 아래 3개 상위 카테고리로 다시 묶는다.
- `법정공휴일` -> 법정공휴일수당
- `평_대체근로수당`, `휴_대체근로수당` -> 대체근로수당
- `평_연장근로수당`, `휴_연장근로수당` -> 연장근로수당
- 수당 화면과 별첨 표기는 내부 코드 대신 `대체근무`, `연장근무`, `법정휴일근무` 라벨을 사용한다.

## 제외/예외 규칙

- Pool 근무자가 수행한 대체근무는 실적 기록에는 남기지만, 실적 관리 노출과 수당 계산/집계/품의 출력에서는 제외한다.
- 임의 시급으로 재승인한 행은 최신 승인 스냅샷의 시급을 우선 사용하며, 기존 승인 이력은 삭제하지 않는다.
- 재승인 확정 시 엑셀 원본을 다시 쓰지 않고, DB 기준 최신 승인 행만 갱신한다. 재승인하지 않은 행은 직전 승인본을 유지한다.
- 퇴직자 선지급 건은 일반 지급 합계와 품의서 2번 항목에서 제외하고, 품의서 3번 항목으로 별도 집계한다.
