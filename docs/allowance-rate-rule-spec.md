# 수당 요율/계산 규칙

## 기준 행

수당 요율은 단일 코드 배율이 아니라 `근로유형 5행 x 기본/연장/야간 3열` 구조로 관리한다.

| 근로유형 | 기본근로수당요율 | 연장근로수당요율 | 야간근로수당요율 |
| --- | --- | --- | --- |
| 법정공휴일 | 1.5 | 1.5 | 1.5 |
| 평_대체근로수당 | 1.5 | 2.0 | 2.5 |
| 휴_대체근로수당 | 1.5 | 2.0 | 2.5 |
| 평_연장근로수당 | 0 | 1.5 | 2.0 |
| 휴_연장근로수당 | 0 | 0 | 0 |

## 계산 축

- 기본근로시간: 총근로시간 기준 최대 8시간
- 연장근로시간: 8시간 초과분
- 야간근로시간: 22:00 ~ 06:00 구간

현재 엔진은 `기본/연장` 분해와 `야간` 프리미엄을 함께 보존한다. 따라서 야간시간은 기본/연장 축과 별도로 line item 으로 계산된다.

## 근로유형 매핑

- `법정공휴일`, `공휴일`, `휴일근로` 계열: `법정공휴일`
- `평_대체`, `대체근로` 계열: `평_대체근로수당`
- `휴_대체` 계열: `휴_대체근로수당`
- `평_연장`, `연장근로` 계열: `평_연장근로수당`
- `휴_연장` 계열: `휴_연장근로수당`

`휴일근로`처럼 휴일 키워드가 있지만 명시 코드가 없는 경우는 우선 `법정공휴일`로 본다. 샘플 실적 파일이 이 값을 사용하기 때문이다.

## 출력/집계 규칙

- 품의/별첨 요약은 아래 3개 상위 카테고리로 다시 묶는다.
- `법정공휴일` -> 법정공휴일수당
- `평_대체근로수당`, `휴_대체근로수당` -> 대체근로수당
- `평_연장근로수당`, `휴_연장근로수당` -> 연장근로수당
