# ShiftMgmt 0.5.1

화면 디자인 다듬기 — 아이콘·색·구성 정리 (기능 변화 없음)

이번 업데이트는 `0.5.0` 후속의 **디자인 정리**입니다. 주요 화면과 창의 아이콘·색·구성을 시안에 맞춰 더 또렷하고 일관되게 다듬었습니다. **기능·데이터·계산 로직은 전혀 바뀌지 않았으며**, 순수하게 보이는 모습만 손봤습니다. 업데이트 후 재승인이나 데이터 변경은 발생하지 않습니다.

## 화면 디자인 통일
- **아이콘 통일** — 화면 곳곳의 아이콘을 일관된 글꼴 아이콘으로 바꿔 더 또렷하고 통일감 있게 보입니다. 섹션 제목, 버튼, 인력 배정 카드(위로/아래로/해제), 빈 영역 안내 등에 적용했습니다.
- **내 정보 창** — 권한을 배지로 표시하고, 데이터베이스·연결 상태를 초록 점으로 보여줍니다. 아래 버튼은 비밀번호 변경(왼쪽)과 닫기·로그아웃(오른쪽)으로 나눠 정리했습니다.
- **인력 상세** — 이름 옆에 머리글자 동그라미(아바타)를 넣고, 근무 배정·기본 정보 수정·시급·변경 이력 제목마다 아이콘을 더해 한눈에 들어오게 했습니다.

## 근무지 등록 단계
- **단계·아이콘 정리** — 1·2단계 표시를 또렷하게 하고, `기본 설정`·`근무 시간 설정`·`조직 구성` 화면의 카드 색 띠와 아이콘을 통일했습니다.
- **근무 시간 바로 보기** — 근무 시간 설정 화면에서 첫 근무 묶음의 시간표가 처음부터 펼쳐져 바로 보입니다.
- **대시보드 안내** — 데이터 안내 배너에 아이콘을 더해 더 알아보기 쉽게 했습니다.

## 안전성
- **기능 불변** — 이번 변경은 모두 화면 표시(CSS·아이콘)만 손본 것으로, 계산·승인·저장 로직과 데이터는 전혀 건드리지 않았습니다.
