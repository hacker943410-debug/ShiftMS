# 2026-04-02 작업 정리

## 오늘 완료한 작업

### 1. `0.2.3` 패치
- 별첨1 PDF 표 폭과 라벨을 출력 안정성 기준으로 다시 조정했다.
- `접속 이력`을 `활동 이력`으로 변경하고 필터 폭과 액션 카테고리를 확장했다.

### 2. `0.3.0` 업무 흐름 패치
- 수당 계산 결과에 `검토대기 / 승인 / 반려 / 품의승인` 상태 흐름을 추가했다.
- 행별 승인, 근무지 단위 승인, 품의 승인 미리보기, 최종 승인 시 자동 백업까지 연결했다.
- `수당 이력`을 `품의 이력`으로 재구성하고 상태 필터를 추가했다.

### 3. 가이드 시스템 전체 배치 구현
- `GuideFlowModal` 공통 엔진을 기준으로 전 메뉴와 세부 모달 가이드를 연결했다.
- 배치 1~5를 통해 `대시보드`, `실적 관리`, `수당 관리`, `근무표 배포`, `운영 관리`, `활동 이력`, `인력 관리`, `근무지 관리`, `품의 승인`, `DB업데이트`, `양식 관리`, `시급 일괄 업데이트`, `패턴 적용된 근무지 추가`까지 가이드를 구성했다.

### 4. 가이드 구조 재설계
- 설명 박스 중심 구조를 `번호형 하이라이트 + 우측 탭 설명` 구조로 바꿨다.
- 우측 설명은 `사용 흐름`, `기능 설명` 탭으로 분리했고, 선행조건과 기대 결과도 읽을 수 있게 정리했다.
- 공통 primitive와 scene별 focus mapping을 정리해 장면별 동작을 통일했다.

### 5. 가이드 검증 체계 보강
- 가이드 전용 Electron smoke를 batch2~5와 전체 실행 단위로 구성했다.
- `사용 흐름 / 기능 설명` 탭 전환, 활성 하이라이트 가시 영역, 포인터와 ripple 상태를 자동 검증하도록 보강했다.
- 검증 중 드러난 `실적 관리 승인 이력`, `근무표 배포 배포 이력`, `운영 관리 공휴일·요율`, `운영 관리 DB업데이트` 장면의 위치를 추가 보정했다.
