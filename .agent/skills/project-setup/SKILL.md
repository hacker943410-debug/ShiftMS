# Project Setup

## Goal
프로젝트의 초기 구조와 설정 파일을 일관된 상태로 유지한다.

## Instructions
1. `PROJECT_INIT.md`와 `AGENTS.md`를 먼저 읽는다.
2. `.codex`, `.agents`, `.context`, `artifacts` 구조를 검증한다.
3. Electron main/preload/renderer 경계가 유지되는지 확인한다.
4. 누락된 기본 파일과 `.gitkeep`을 복구한다.
5. 검증 결과는 짧게 보고한다.
